## Baseline and method

This package reconstructs implemented design at SDK commit `f07e558ed04c81154687d7efcc6312591e7f6f7d`. It is based on a complete recursive repository tree, all **258 core/runtime Python files**, and **282 example files** selected for declarations, entry points, acquisition, projection and representative end-to-end paths. Including supporting SDK documents and package metadata, **544 files** were retrieved and checked against their Git blob hashes.

Every retrieved Python file was parsed with Python's AST. The corpus contains **1031 class definitions** and **3914 function/method definitions**, including nested and private definitions. The package inventory was derived from imports; selected lifecycle and control paths were then read directly to establish sequence and ownership. These counts are inspection scope, not API counts or test results.

## Diagram conventions

- Architecture boxes are responsibility groups unless explicitly described as processes or stores.
- Module arrows in the selected dependency maps denote inspected imports; the larger dependency table includes function-local and type-checking imports.
- Class diagrams show selected real fields/methods. Dashed realization means structural Protocol conformance, not declared Python inheritance.
- Sequence arrows summarize the source call path. Composite paths, conditional refusals and persistence failures are stated separately.
- Example topology is based on executable code and declarations. Historical README measurements and unimplemented specification intentions are not promoted to current runtime guarantees.

## Verification limits

No SDK unit suite, hosted CI run, bank database query, network door or live example was executed for these documents. This is a static design reconstruction. Runtime viability, security closure and release readiness require their own evidence. This inventory describes the fixed Oct-9 source snapshot; later SDK changes are outside these counts and are summarized by the current-main overlay.

The documents are Markdown with Mermaid diagrams. Source links use this immutable commit. Relative documentation links and source-path existence are checked; Mermaid diagrams are parsed and rendered separately during validation.

These source-inventory counts and blob hashes belong to the Oct-9 reconstruction pin and are intentionally not repinned. The current technical reference is synchronized separately; see [Current-main design delta](11_CURRENT_MAIN_DELTA.md) and [SDK Update Status](../SDK_UPDATE_STATUS.md).
