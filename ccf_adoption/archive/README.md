# Project history archive

[Project history](project/README.md) preserves the internal project charter, phase plans, checkpoints, review records, source manifests, and QA records used to build the adoption documentation.

The files under `project/` retain their historical content. Phase statuses and checkpoints describe the state when each record was written; they are not a current release dashboard. In particular, the original project overview retains its initial phase-status table. See the [Phase 5 release-readiness record](project/phase-5/RELEASE_READINESS.md) and [Decision Replay closure record](project/phase-5/DECISION_REPLAY_CLOSURE.md) for the later release history.

For current learning and implementation guidance, begin with [Start Here](../03-start-here/START_HERE.md) or the [Developer & Engineer Guide](../05-reference/README.md). The archive is internal project history and is not part of the public learning sequence.
