# CCF Adoption Project

This directory contains the internal project constitution for building `ccf_adoption` into the authoritative learning, implementation, assurance, and adoption environment for the Cognitive Context Fabric (CCF) SDK, with a primary focus on financial-services use cases.

These files govern how the adoption portal is built. They are not intended to be part of the public learning navigation unless explicitly promoted later.

## Governing documents

- `PROJECT_CHARTER.md` — mission, audiences, objectives, quality bar, and non-negotiable boundaries.
- `SOURCE_MODEL.md` — repository roles, source-of-truth hierarchy, provenance, conflict handling, and asset reuse rules.
- `PHASES.md` — phased execution plan and internal checkpoints.
- `CHECKPOINTS.md` — approval states, branch/merge discipline, and checkpoint record format.
