# Start Here — CCF Story

## Status

Phase 3 working content on `phase-3-start-here`.

This directory is the front door into the Cognitive Context Fabric. It is intentionally shorter and more task-oriented than the whitepaper. The goal is to let a technically sophisticated newcomer understand what CCF is, why it exists, where it fits, and what to read or do next.

## Pages

- `START_HERE.md` — primary front-door narrative and routing page.
- `WHY_CCF.md` — the architectural problem CCF addresses and why existing data systems remain necessary but insufficient for agentic decision-making.
- `ARCHITECTURE_AT_A_GLANCE.md` — Systems of Record → Signal Generation → Cognition, `G(E,R,T,P,Π,L)`, L1–L6, Control/Data Plane, and layering posture.
- `CONTEXT_PRODUCTS.md` — the primary consumer-facing primitive: Data Products → Context Products, derived-not-stored, governed and decision-scoped.
- `RESOURCES.md` — overview video, released whitepaper, architecture deep dives, and routes into later portal sections.

## Phase 3 approval test

A newcomer should be able to answer:

1. What is CCF?
2. Why is a cognition/context layer needed for agents?
3. How does CCF relate to existing data platforms and Data Products?
4. What is a Context Product?
5. What are the six CCF layers?
6. What do policy, perspective, time, and lineage add beyond ordinary retrieval?
7. Where should I go next if I am evaluating, consuming, assembling, governing, or operating CCF?
