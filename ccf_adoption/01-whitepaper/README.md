# Cognitive Context Fabric Whitepaper

This directory is the distribution home for the published Cognitive Context Fabric whitepaper used by the CCF adoption materials.

## Current published version

**CCF Whitepaper v1.2** — `CCF_Whitepaper_1-2.pdf`

The authoritative source, construction history, and revision history remain in the read-only source repository `drcastillo/ccf`. The copy placed here is a versioned distribution snapshot for the adoption portal; it is not the source of truth for whitepaper development.

Do not edit the PDF in this repository. Whitepaper changes originate in `drcastillo/ccf` and are promoted here only after a version is published.

`provenance.yaml` records the exact source commit, source blob, SHA-256 digest, size, and page count for the snapshot expected here.

When a later version is approved, add the new versioned PDF, update `provenance.yaml`, and retain prior published snapshots under `archive/` if historical copies are needed in the adoption portal.
