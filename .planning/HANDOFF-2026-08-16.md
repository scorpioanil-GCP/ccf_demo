## The lesson of this phase, and it has not stopped being true

**Every defect found in Phase 17 has been in verification machinery. Not one in
mechanism.** Five instances, all one shape: **a check that stops checking
without going red.**

1. The citation sweep dropped citations whose target basename was ambiguous —
   live worktrees made it check *less*, silently. **It passed vacuously for a
   full wave with two real defects behind it**, and the orchestrator defended
   the vacuous green twice against three correct executors.
2. The repair then filtered on the **absolute** path, so a checkout rooted
   inside `.claude` matched every file and walked **zero**. Failing open became
   failing closed.
3. `MINIMUM_GATE_CALL_SITES` sat at floor 11 with 11 witnesses and **zero
   headroom** — every witness inside a *retiring* example tree.
4. `tools/dump_surface.py` called `pkgutil.walk_packages` with no `onerror`, so
   an `ImportError` dropped an entire subtree: three subpackages, twelve public
   names, invisible behind green.
5. **`gate-tools` was added to `make ci` but never to `make ci-core`** — and
   `ci-core` is what every executor runs. Three waves shipped past a red gate.

**The root cause worth carrying:** Python's discovery primitives default to
lenient. `walk_packages` skips on error, `rglob` matches nothing silently,
`dict.get` returns `None`. **A gate built on a lenient primitive inherits its
leniency unless you override it explicitly.** For every assertion that walks,
resolves, discovers or counts, ask what it does when it *cannot* resolve
something — and make the sabotage controls include the empty and unresolvable
cases, not only the wrong-value case.

**The instruction that keeps earning its keep:** tell every executor to
**expect its plan to be wrong and to dispute with a measurement rather than
route around**. Seven for seven this phase — including `17-04` finding its
central field type impossible, `17-05` finding its key link impossible, and
three executors correctly disputing a baseline the orchestrator defended.

## Standing hazards — read before touching anything

- **NEVER run `state.*` or `roadmap.*` SDK writers.** Five confirmed
  corruptions of `.planning/STATE.md`. Hand-edit, back up, diff.
- **No bare `python` on PATH.** Use `.venv/bin/python`; `Makefile:10` defines
  `PYTHON := .venv/bin/python`.
- **`grep` is a ugrep shim that auto-recurses.** Use `command grep` for
  anything quoted as a measurement.
- **Do not write a `path.py:NN-MM` citation in prose** — cite
  `path.py::Symbol` (`D-IMPL-114`). The sweep cannot distinguish a citation
  from a *quotation* of one, so documenting a citation defect reproduces it.
- **`examples/` is NOT typechecked** (`[tool.mypy] files = ["src","runtime"]`)
  — a mypy claim about example code is vacuous.
- **`.pyc` staleness survives a byte-count-preserving `git checkout`.** If a
  revert seems not to take:
  `find src -name "__pycache__" -type d -exec rm -rf {} +`.
- **Worktrees spawn stale** — six confirmed instances. Every executor must
  fast-forward and symlink `.venv` before starting.
- **A tree-walking gate measured inside a worktree is not evidence about the
  branch**, and vice versa — the orchestrator must re-measure on the main
  checkout. See `DEF-17-04`.
- **`cinv01a-prompt-shape` false-positives** on long string literals by length
  alone. Do NOT weaken an assertion to pass it.
- **Adding a module with `__all__` moves the public-surface manifest** — expect
  to write `docs/surface-changes/<plan>-*.md` and run `make surface-changes`.
- **`RETIREMENT-COUPLINGS.md` records Makefile line numbers**, so any Makefile
  edit invalidates it. Regenerate with
  `PYTHONPATH=src:runtime .venv/bin/python tools/retirement_sweep.py --report`
  (it writes the file *and* prints a summary — do not redirect stdout over it).
