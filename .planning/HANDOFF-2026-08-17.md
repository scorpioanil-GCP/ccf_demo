## Standing hazards — read before touching anything

1. **`make … | tail -N` reports TAIL's exit code, not make's.** Capture with
   `make X > log 2>&1; echo "EXIT=$?"` **and branch on the value**. Echoing it
   is not acting on it — a gate whose result is printed but not branched on is
   decoration. This session made both mistakes.
2. **No bare `python` on PATH.** Use `.venv/bin/python`; the `Makefile` defines
   `PYTHON := .venv/bin/python`.
3. **The venv's editable install resolves `ccf` to the MAIN CHECKOUT.** Any
   ad-hoc measurement without `PYTHONPATH=src:runtime` reads code you did not
   write. `make` targets set it; ad-hoc `pytest` and `python -c` do not.
4. **`grep` is a ugrep shim that auto-recurses.** Use `command grep` for
   anything quoted as a measurement.
5. **`RETIREMENT-COUPLINGS.md` records Makefile line numbers AND sweeps the
   planning tree — including a plan's own SUMMARY.** Regenerate with
   `PYTHONPATH=src:runtime .venv/bin/python tools/retirement_sweep.py --report`
   (writes the file *and* prints a summary — do not redirect stdout over it).
   **Order matters: write the SUMMARY first, then re-sweep.** Regenerating
   before writing it left `gate-tools` red on merge twice in one day.
6. **Never run `state.*` or `roadmap.*` gsd-sdk writers.** Five confirmed
   corruptions of `.planning/STATE.md`. Hand-edit, back up, re-parse the YAML,
   diff.
7. **Citations of a decision entry use the STABLE ID** (`D-IMPL-87`) and the
   file, with **no line number** — `D-IMPL-144`. Cite code as
   `path.py::Symbol`, never `path.py:NN` (`D-IMPL-114`).
8. **Neither `examples/` nor `tests/` is typechecked**
   (`[tool.mypy] files = ["src","runtime"]`). A mypy claim about either is
   vacuous; `make typecheck` is the real check.
9. **Adding or reshaping a public name moves the surface manifest.** Write
   `docs/surface-changes/<plan>-*.md` and run `make surface-changes`; a reshape
   also needs `tools/dump_surface.py` re-run to regenerate the committed
   manifest.
10. **Actions' `checkout` uses `fetch-depth: 1`.** A shallow clone's grafted root
    appears to introduce every file, so `git log -- <path>` returns HEAD's own
    subject. Ask `git rev-parse --is-shallow-repository`; do not infer.
11. **`.pyc` staleness survives a byte-count-preserving `git checkout`:**
    `find src -name "__pycache__" -type d -exec rm -rf {} +`.
12. **Worktrees spawn stale and without a venv.** Fast-forward and

    gate measured inside a worktree is not evidence about the branch

## The lesson this phase kept proving, at eleven instances

**Every defect found was in verification machinery or in plans — never in
mechanism.** A citation sweep passing vacuously; a gate wired into `make ci` but
not `ci-core`; CI running a different command from the local gate for months;
a provenance test that could never pass under a shallow clone; two floors that
stopped equalling their counts; a docstring promising a clock over code reading a
config literal.

**The shape they share:** treating *absence of a failure signal* as *presence of
a success signal*. A pipe returning the wrong status, a tail window that happened
to contain no error, a null conclusion read as OK. The correct model always has
three states — pass, fail, and **don't know** — and the bug is collapsing
"don't know" into "pass".

**Two rules that came out of it, now written into the code they govern:**

- *A floor is only a floor while it equals the count, and the plan that adds a
  witness is the plan that must raise it.* Adding a witness makes the assertion
  **more** satisfied, so nothing goes red to say so — the one direction a floor
  cannot detect on its own.
- *A mirror asserted in a comment is not a mirror.* Prose drifts out from under
  code; a docstring, comment or README asserting a behaviour is not evidence the
  behaviour holds.

**The instruction that earned its keep, twelve for twelve:** tell every executor
to **expect its plan to be wrong and to dispute with a measurement**. `17-11`
found its own premise false; `17-12` found the spec wrong twice; `17-13` found
its fixture could not exercise debt at all; `17-08` found its own sequence
impossible; and the single-agent reviewer found both close-review blockers by
**executing** the module's own helpers rather than reading them.
