## The per-member base resolution, re-derived — by MEMBER, never by SHA

Re-derived in this session for **all 21 members of all six pathspec constants**. Every one resolves and every one produces a non-empty diff.

**The SHAs are deliberately not quoted.** A rebase or a squash-merge to `main` moves every one of them; the control stays honest because it re-derives, and a SUMMARY quoting them goes stale. What is quoted is the mechanism:

```
last   = git log -1 --format=%H -- <member>     # refuses if empty
parent = git rev-parse --verify <last>^         # refuses on non-zero exit
assert fabric_diff(parent, (<member>,)).strip()
```

| Constant | Members | All resolve | All diffs non-empty |
|---|---|---|---|
| `FABRIC` | `src/`, `runtime/` | yes (2/2) | yes |
| `FENCE` | `src/`, `runtime/`, `examples/`, `public/`, `pyproject.toml` | yes (5/5) | yes |
| `UAT_RECORDS` | the eleven `*-VERIFICATION.md` records | yes (11/11) | yes |
| `PINNED_FILES` | `tools/lints/citations.py` | yes (1/1) | yes |
| `TESTS_TREE` | `tests/` | yes (1/1) | yes |
| `CHANGED_TREE` | `.planning/` | yes (1/1) | yes |

Nineteen of those (`FABRIC` + `FENCE` + `UAT_RECORDS` + `PINNED_FILES`) are `CONTROL A`'s subjects; one (`TESTS_TREE`) is `CONTROL 13`'s. `CHANGED_TREE` is now nobody's subject and is retained only because `asserted_pathspecs()` enumerates it.

**The self-guard, re-measured:** `git log -1 --format=%H --` returns the **empty string and exit ZERO** for `scr/`, `runtimes/`, `example/`, `tests-typo/` and `tools/lints/citation.py`. That is precisely the silent skip, and it is refused by name.

**The root commit resolves:** `git rev-list --max-parents=0 HEAD` returns exactly one commit, and `git rev-parse --verify <root>^` exits 128. That is what makes `derived_base.no_parent` a reachable limb rather than a dead one.

**CI compatibility, re-verified:** both `docs` jobs use `fetch-depth: 0` (`.github/workflows/ci.yml:166` and `:331`), so every parent commit resolves in CI.
