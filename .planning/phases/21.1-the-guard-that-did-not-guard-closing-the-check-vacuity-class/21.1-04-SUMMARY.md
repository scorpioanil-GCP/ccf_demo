The first draft of the amended cell cited the split document the way `D-IMPL-179` contemplates — a `.planning/` line citation, the shape `LOOSE_CITATION` was built in wave 3 to make legal. It extracted correctly, resolved correctly, and **reddened the module**:

**It is a false positive by construction.** Measured on the cell:


The widened match starts one character earlier and **covers the lint's span entirely** — it did not drop anything, it corrected it. But the check's subsumption predicate is `set(lint_pairs) - set(widened_pairs)` compared as **path STRINGS**, and `planning/…` is not `.planning/…`. So:

> **The check can never be satisfied by a dotted citation — the exact shape `LOOSE_CITATION` exists to admit.**

Wave 3's own record says why it was green: *"the real ledger yielded the SAME 127 citations before and after… no existing citation begins with a dot."* The check was true only over a tree with no dotted citation, which is this phase's thesis arriving inside this phase's own fix. It is also failure mode 1 from the control-discipline brief — **the subject never reached the branch under test** — and it took the first real *use* of the mechanism, a wave later, to produce a subject.

**Why it was not fixed here, stated rather than assumed:**

- This plan is documents-only by its own terms and by wave discipline: the ROADMAP serializes module writes because *"every implementation plan writes to the same single module… so no two can share a wave"*.
- A fix needs a **control**, committed before it and watched failing (`D-IMPL-170`, criterion 8). The next free control number is **24**, and plans `21.1-05` through `21.1-08` are written against that. Taking 24 here would collide with them.
- The honest repair is a predicate change — subsumption by **span containment** rather than by path-string equality, keeping the anti-vacuity clause — which is a real change to shipped machinery, not a papering-over.

**It cannot be dodged by re-spelling.** `VAC-03`'s only possible evidence lives under `.planning/phases/`, so plan `21.1-09`'s verdict for `VAC-03` needs a `.planning/` citation, and today any dotted citation reddens the module. **`RR-11` must close before wave 9.**
