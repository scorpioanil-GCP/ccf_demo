<criterion_8_is_unsatisfiable_here_and_this_is_the_reading>
**Criterion 8 says every control this phase adds is "watched failing against the pre-fix module and
passing against the post-fix module". For these eight controls there IS no fix — the refusals already
ship and work.** Run them against the pre-fix module and they PASS. Taken literally, criterion 8 and
criterion 12 cannot both be satisfied: criterion 12 demands controls over refusals that already work,
and criterion 8 demands those controls be seen failing against a module in which they do not fail.

**The reading:** for a control over a refusal that already ships, the RED is produced by NEUTERING
the aimed limb — the exact mutation-testing method that found the eight in the first place — and that
neutered run is what the SUMMARY records. It is stronger evidence than the pre-fix run, not weaker:
a pre-fix run shows the control failing against a module that lacks the guard; a neutered run shows
it failing against the shipped module with exactly one named branch disarmed, which is what
"proven to reach that branch" actually means.

Record both readings in the SUMMARY and put the criterion-8 conflict to Dave at the close.
</criterion_8_is_unsatisfiable_here_and_this_is_the_reading>
