  each such control is run against the pre-fix module and observed GREEN there"; criterion 8 asks
  that "every control this phase adds is watched failing against the pre-fix module and passing

  criterion 8's describes the CONTROL TEST's own pytest outcome. Both are evidenced by one
  four-cell table per control: subject pre-fix, subject post-fix, control test pre-fix, control
  test post-fix.
- **Criterion 8 is unsatisfiable for a control over a refusal that already ships** — see plan
  `21.1-06`, which is where that bites.

**The implementation hazard, measured, and the choice this plan makes.** `git ls-files --error-unmatch`
gives per-member semantics in a SINGLE subprocess call and names the offending member in stderr, and

the whole module runs in under two seconds.
