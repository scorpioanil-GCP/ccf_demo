## The control roster this phase adds, by landing order

The module's convention (`:1978-1984`): a control takes the next free number in landing order and is
never renumbered or duplicated. The next free number at the phase's start is **18**; the run `1..17`
is contiguous, plus letters `A`, `B`, `C` and `4b`, `5b`, `9b`, `17b`.

| Plan | Controls | Subject |
|------|----------|---------|
| `21.1-01` | **18** | one mutated member per multi-member constant (`FABRIC`, `FENCE`, `UAT_RECORDS`) |
| `21.1-02` | **19** | the dual-verdict cell, handed to both verdict gates |
| `21.1-03` | **20, 21, 22, 23** | table duplicate · checkbox duplicate · empty index · the `.planning/` citation shape, accepted AND refused |
| `21.1-06` | **24–31** | `tracked_under` exit · cell count · empty checkbox channel · `_doctored` · `_table_line` · moved-path branch · `base_ledger_text` exit · empty roster |
| `21.1-06` | **32, 33** | the dispatcher's unregistered-limb guard · the `_NEUTERED` off-switch guard |
| `21.1-07` | **34, 35, 36, 36b** | registry coverage · limb aim · discriminator aim · guard aim |
| `21.1-08` | **37, 38** | the derived base's two refusals · pathspec aim |

**The five aim kinds** a `CONTROL_AIM` entry may declare: `limb`, `pathspec`, `discriminator`,
`guard` and `meta`. Each entry carries a SET of targets, never one — `CONTROL C` covers two limbs and
`CONTROL A` four constants — and each aim loop quantifies per target. `meta` is excluded from every
invocation loop and is the regress-stopper for the aim-proving controls themselves; it is not a home
for a control that does not fit, which is why `CONTROL 32` and `CONTROL 33` take `guard`.

## Selector discipline

**A `-k` selector that matches the WRONG test exits 0.** A selector matching nothing exits 5 and is
visible; a selector matching an already-green sibling is silent and reports success over a run that
never touched its subject. Seven such selectors were found in this phase's own plans at plan-check,
left behind by a control renumbering — one of them on the task whose entire purpose is to watch
`CONTROL 38` fail.

Every task that adds a control therefore carries a SELECTOR PROOF beside its run: collect with the
selector and require a test NAMED for that control number to be among the collected node ids.

    for n in 24 25 26 27 28; do PYTHONPATH=.:src:runtime .venv/bin/python -m pytest \
      tools/docs_tests/test_requirement_ledger.py --collect-only -q -k "control_$n" \
      | grep -q "test_control_$n" || exit 1; done

It is deliberately a per-plan verification command rather than a standing test in the module: a gate
that parsed this phase's PLAN files would be a new mechanism over `.planning/` records that the
phase's own fence does not authorise, and it would leave phase-specific machinery in a permanent
suite. The standing half of the same concern lives in the module as the frozen `CONTROLS` roster,
which is what stops the enumeration silently dropping a control.

## The RED / GREEN protocol, per control (criterion 8)

`D-IMPL-170`: a control never OBSERVED failing is not a control. Two shapes, because criterion 8's
literal wording does not fit the second:

**Shape A — a control over a refusal this phase ADDS.** Commit the control BEFORE the fix; run it;
record the RED verbatim. Land the fix; run it; record the GREEN. Then apply the mutation against the
POST-fix module and watch the refusal a second time.

**Shape B — a control over a refusal that ALREADY ships** (everything criterion 12 forces in plans
`21.1-05`/`06`). There is no pre-fix module in which it fails. The RED is produced by NEUTERING the
aimed limb through `neutered()`, and that run is what is recorded. It is stronger evidence, not
weaker: it shows the control failing against the SHIPPED module with exactly one named branch
disarmed, which is what "proven to reach that branch" means.

Measured pre-fix behaviour each Shape-A control must reproduce as its RED:

| Mutation | Pre-fix result |
|---|---|
| `("scr/","runtime/")` through `fabric_diff` | returns `''` — no refusal |
| `FENCE` with `"example/"` | returns `''` — no refusal |
| `HARD-02` cell → `Complete — later **Partial** (…)` | 8 gates, **0** refusals |
| `HARD-02` row duplicated with `Phase 99` | 144 rows parsed, dict keeps 1, 5 gates return `[]` |
| `_index()` thinned to `{}` | the moved-path branch accepts silently |
| a `.planning/…md:1` citation | `citations_in_status_cells` extracts **nothing** |
| `TESTS_TREE` → `("tests-typo/",)` (post-`VAC-01`) | must refuse per member; pre-`B-1` it was 45 green |
