## THIS PHASE BUILDS NOTHING

A disposition is a VERDICT ABOUT THE TREE, never a change to it. `Discharged`
means *the work is already done and here is the evidence*; it never means *I did
the work now*. If a row would need work to be `Discharged`, it is
`Deferred to v0.3` with a named inheritor, or `Dropped` with a named ruling.
There is no fourth option and there is no building.

## THE FOUR-ROW KNOT IS OUT OF SCOPE HERE

`DOCS-14`, `DOCS-17`, `EXAM-02` and `CLNT-17` are one knot that cannot be
sequenced apart. `23.1-03` disposes all four together. **Do not write a
disposition, a limb, a verdict or a cell edit for any of them in this plan**, and
do not let a cross-reference in one of the nine rows become an implicit verdict
on one of the four.

## The ledger has TWO channels

- checklist: `- [ ] **DOCS-03**: … — **PARTIAL** (…)`
- traceability: the table from `| Requirement | Phase | Status |`, e.g. `| DOCS-03 | Phase 16 | **Partial** …`

Phase 23's sabotage **S-L4** set one row to `Partial` in one channel and
`Not built` in the other and **114 tests passed**. Both channels get the
disposition; **I-2** proves they agree.
