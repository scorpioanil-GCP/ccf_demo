confirmed item `#19`'s premise that no such entry exists. **Its positive control

the record empty: `D-GATE` entries are **bold lines**, not `###` headings, and

required either. Corrected reader `^\*\*D-GATE-<id>` returns 17 entries; negative
control `^\*\*D-GATE-99\.9` → 0. **Without the control this would have shipped as
a false absence** — the exact defect class this phase is named for, produced once
more inside the file written to dispose it. **That is now nine waves running in
which the wave found the class in its own work.**
