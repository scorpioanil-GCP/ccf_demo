## Re-measuring both premises against the tree

The reason this is a RE-measurement rather than a reading: one premise is
already known to be false, and the figure that falsified it is itself carried in

### Premise 1 — is `s1-01` the last shipped `examples/` call site of `refuse_request`?

**NO.** Measured three ways, each with its control.

**M1 — files under `examples/` naming the symbol.**

```
git grep -l "refuse_request" -- 'examples/**/*.py'
```

→ **3 files**: `examples/s1-00-companies-over-revenue/consume.py`,
`examples/s1-00-companies-over-revenue/produce.py`,
`examples/s1-01-hello-context-product/spine.py`.

- *Negative control:* `git grep -l "refuse_request_zzz"` over the whole tree → **0**.
- *Positive control on the pathspec:* `git grep -l "ContextProduct" -- 'examples/**/*.py'` → **2** files. The pathspec names tracked files, so the 3 is a measurement and not a spelling accident.

**M2 — which of the three are CALL sites, resolved by AST rather than by grep.**
A grep hit is a mention; a call site is a call. An `ast.walk` over each module,
matching `ast.Call` whose callee name is `refuse_request` and reporting the
enclosing function, returns:

| File | Enclosing symbol of the call | Verdict |
|---|---|---|
| `examples/s1-00-companies-over-revenue/produce.py` | `::assemble_and_serve` | **CALL SITE** |
| `examples/s1-01-hello-context-product/spine.py` | `::assemble_and_serve` | **CALL SITE** |
| `examples/s1-00-companies-over-revenue/consume.py` | — none | mention in a COMMENT only |

- *Positive control:* the same reader asked for `print` returns `['main', 'report']` in `consume.py` — **the file that returns nothing for `refuse_request` is a file the reader demonstrably reads**. That is what makes its empty result a finding rather than a blind spot.
- *Negative control:* the same reader asked for `refuse_request_zzz` returns `[]` in all three.

**THE FIGURE IN THE ROADMAP AND IN DAVE'S BRIEF IS THREE, AND AT THE AST LEVEL
IT IS TWO. Named, not rounded, and not silently adopted.** Three `.py` files
NAME the symbol; **two of them CALL it**. The correction does not move the
ruling one inch, because it cuts the same way: `s1-00/produce.py::assemble_and_serve`
is an independent, shipped, non-`s1-01` call site under `examples/`. The premise
*"deleting `s1-01` removes the LAST shipped `examples/` call site"* is **FALSE
under both readings**.

**M3 — what the standing seam-obligation gate actually asserts**, since the
premise leans on it. `tools/docs_tests/test_resolver_seam_obligations.py::test_both_seams_cite_both_call_sites`
requires each seam docstring to cite **at least two DISTINCT example paths**,
and `::EXAMPLE_PREFIX` was widened by Phase 23 to `("examples/", "archive/examples/")`.
The gate is about **docstring citations that resolve**, not about a last call
site surviving. The cited spans are
`runtime/ccf_runtime/mcp/egress.py::ProductResolverProtocol` and
`runtime/ccf_runtime/mcp/experience.py::ExperienceProductResolverProtocol`.
So even the gate the premise invokes does not say what the premise says it says.
