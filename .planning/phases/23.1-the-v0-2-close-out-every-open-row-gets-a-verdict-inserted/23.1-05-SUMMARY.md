**Two entry forms exist and a reader that knows only one is wrong by 29.** Ids
`1`–`29` are written as `- **D-IMPL-NN — …**` bullets; `30`+ are written as
`**D-IMPL-NN — …**` paragraphs. The first version of the extractor knew only the
second and reported **172** defined ids with a 28-wide "gap" at `2`–`29` — a
false-absence that, taken at face value, would have handed this entry an id that
CLAUDE.md §12 already scaffolds. Caught by reading the gap list, then corrected.
Recorded rather than tidied.

**The tightening that removes the last doubt.** The loose reader matches any
line beginning with a bolded `D-IMPL-N`, which over-matches 12 ids whose entry
bodies happen to start a line with a bolded self-reference — an over-match can
only produce a false TAKEN, never a false free. Re-read with the strict entry
form (`**D-IMPL-N — `), the two readers agree exactly: **201 ids, and the set
difference in the direction that would matter is empty.**
