## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Installed-distribution → fabric (discovery) | `importlib.metadata` entry points in the `ccf.graph_backends` group, read by `ccf.graph.registry.declared_names()`. **New in this phase** — CCF's first plugin surface. | Adapter names, distribution names, distribution versions, entry-point target strings. No code executed. |
| Installed-distribution → fabric (resolution) | `ccf.graph.registry.resolve()` — the one place third-party module-level code runs, and only for the adapter a manifest named. | A `BackendRegistration` record, plus whatever the third party's module body does. Type-checked and name-checked on arrival. |
| Third-party adapter → operator-visible refusal | Exception raised by a third party's module body during `EntryPoint.load()`. | Exception **type name** and the declaring distribution's identity only. `str(failure)` is dropped (F1). |
| Process environment → fabric | `os.environ.get` in `ccf.deployment.manifest._resolve_secret_references` — the one production environment read under `src/ccf`. | Credential values, wrapped immediately in `pydantic.SecretStr`. |
| Manifest (content-addressed, persisted) → fabric | `DeploymentManifest.backend`, `.backend_secrets`. | Adapter name and credential **reference names** (`field`, `env_var`). Never a credential value. |
| Fabric → Decision Replay record | `AdapterPin` → `record.py` dimension 2 (`graph_adapter`, `graph_adapter_version`, `graph_secret_refs`). | Adapter name, version, sorted reference **names**. `canonical_bytes` refuses `SecretStr`, so a value cannot be hashed in. |
| Unauthenticated/low-privilege HTTP caller → deployment inventory | `GET /backends` (`runtime/ccf_runtime/http_api/routes/backends.py`) — the one new network endpoint this phase created. | Success: adapter **names** only. Refusal (503): the registry's own message, which names offending distributions but never versions. |
| Third-party adapter → graph write handle | `BackendRegistration.make_writer`, called only by `ccf.boot.boot`. | A writer object, admitted only if `isinstance(..., BaseGraphWriter)` (`adopt_writer`); the boot token still gates one writer per graph identity. |
