## Sampling Rate

- **After every task commit:** `make lint` + the targeted test file (both seconds)
- **After every plan wave:** `make ci-core`
- **Before `/gsd:verify-work`:** `make ci` + `make legs` green, plus the D-11
  out-of-tree adapter run with V8's `git diff --stat src/ccf` recorded verbatim
- **Max feedback latency:** < 60 seconds at task level

**A skip that replaces a pass counts as a regression** (V17). The leg targets set
`CCF_REQUIRE_*` so a missing container fails rather than silently skips.
