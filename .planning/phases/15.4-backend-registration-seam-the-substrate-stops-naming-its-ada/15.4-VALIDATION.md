## Sampling Rate

- **After every task commit:** `make lint` + the targeted test file (both seconds)
- **After every plan wave:** `make ci-core`
- **Before `/gsd:verify-work`:** `make ci` + `make legs` green, plus the D-11
  out-of-tree adapter run with V8's `git diff --stat src/ccf` recorded verbatim
- **Max feedback latency:** < 60 seconds at task level, with six stated
  exceptions

**The six exceptions, named rather than averaged away.** Six tasks end in an
integration command that takes minutes, not seconds:

| Task | Command | Why it cannot be seconds |
|---|---|---|
| 15.4-03 task 3 | `make legs` | Four live database containers; it is the regression net for a 2,230-line relocation |
| 15.4-04 task 2 | `make leg-fluree` | One live container leg; the WR-05 fix is a store-construction change, so the leg is where it is proven |
| 15.4-05 task 2 | `make typecheck && pytest tests perf … && make legs` | Twenty-three migrated `boot()` call sites across all four containers; carries the wave's strict-mode check because tasks 1 and 2 are one commit |
| 15.4-06 task 3 | `make typecheck && pytest tests/deployment && <dry run> && make examples && make docs-strict` | Twelve migrated example call sites; examples run in CI, so a missed one is a red build. Also carries the wave's strict-mode check (tasks 2 and 3 are one commit) and the one pre-registration full-tree lint sweep |
| 15.4-10 task 3 | `make install && make ci-core` | Entry points live in build-time metadata, so the install is the thing under test |
| 15.4-12 task 2 | `make lint && make ci && make legs` | The phase-close sweep; it is supposed to be everything |

Each of these six also carries fast per-criterion checks in its
`<acceptance_criteria>`, so the sampling is not sparse — a failure is visible in
seconds and only the *final* confirmation is slow. This is a documented
exception to the latency line above, not a gap in it.

**A skip that replaces a pass counts as a regression** (V17). The leg targets set
`CCF_REQUIRE_*` so a missing container fails rather than silently skips.
