    does — `create_app(ApiDependencies(...), acknowledge_insecure_default=True)` — and writes
    `json.dumps(app.openapi(), indent=2, sort_keys=True)` plus a trailing newline to `openapi.json`

    Routers are mounted unconditionally, so the emitted schema is independent of the injected

    state the determinism recipe (`sort_keys=True` removes dict-ordering sensitivity;
    `fastapi==0.140.0` and `pydantic==2.13.4` are exact pins, so the `components.schemas` shapes
    are fixed) and its corollary: a FastAPI bump will move the spec, and that is a desirable,
    reviewable diff rather than a bug.

    Same CLI posture as the other `tools/` scripts: `main(argv)` returning `int`, ending with
    `raise SystemExit(main())`. Support a `--check` flag that writes nothing and returns 1 when
    the on-disk file differs, so the tool is usable both as a regenerator and as a standalone
    check.

    In `Makefile`: add `openapi` to `.PHONY` in the docs group and an `openapi:` target running
    `$(ENV) $(PYTHON) tools/dump_openapi.py`, with a `## ` help string naming D-12 and stating
    that the committed spec is the drift baseline. Do not touch the `ci:` line.

    Run the target and commit the produced `openapi.json`.
