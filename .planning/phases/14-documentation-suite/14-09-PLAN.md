<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unapproved measurement → committed baseline | D-IMPL-70 makes this crossing a human-authorized act, not an automated one |
| committed baseline → published performance claim | Published numbers are read as commitments by adopters |
| host environment → measured numbers | The numbers are only meaningful with their environment stated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-43 | Repudiation | A baseline is recorded without the Dave-gated approval D-IMPL-70 requires | mitigate | Task 2 is a blocking human checkpoint; the plan is `autonomous: false`; on rejection Task 3 does not run and nothing is committed |
| T-14-44 | Spoofing | PERFORMANCE.md publishes a number no committed file supports, or one transcribed and gone stale | mitigate | The page includes the baseline file whole; prose transcription of medians is asserted absent by grep |
| T-14-45 | Spoofing | Published numbers are read as a cross-environment guarantee | mitigate | A claims-boundary section states the runner-class comparability limit and the opt-in gating posture explicitly |
| T-14-46 | Tampering | An automated path to writing `perf/baselines/` is introduced, quietly ending the ritual | mitigate | The baseline is written by hand; `tests/perf_gate`'s source assertion that `gate.py` has no write path is re-run as an acceptance criterion |
| T-14-47 | Information Disclosure | The environment manifest exposes host detail beyond what the numbers need | accept | The manifest is runner class, host characteristics, Python version, commit and date; the repo is private and this is the minimum a reader needs to interpret the numbers |
| T-14-48 | Repudiation | A benchmark silently stopped measuring real work and the baseline enshrines the wrong thing | mitigate | Task 1's review step checks medians for plausibility against the documented budget table and stops rather than proceeding on an implausible result |
</threat_model>
