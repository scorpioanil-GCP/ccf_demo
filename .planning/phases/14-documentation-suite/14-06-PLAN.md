by hand.

**On this plan's file count (21 content pages across two tasks — the heaviest in the phase).**

page contains authored technical content. Each is a framing paragraph plus `:::` identifier lines
drawn from an inventory that research already grep-verified path by path, with mkdocstrings and
griffe-pydantic producing every signature, field, type and schema. The per-page authoring cost is
one paragraph; the expensive work — deciding the selection — was done in research and is consumed
here as a table, not rediscovered. Splitting would duplicate that table's context across two
executors and add a wave dependency for no reduction in the work either would do.
</objective>
