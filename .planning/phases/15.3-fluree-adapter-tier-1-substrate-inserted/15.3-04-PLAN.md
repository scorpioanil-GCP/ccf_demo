<objective>
Promote traversal into the engine — but only after the two probes that bind stage
2 have run, and only at byte-identity over the full corpus.

Purpose and the phase's dominant risk in one paragraph: **the Neo4j walk does not
translate.** `_WALK_EDGES_ALL` (`backends/neo4j.py:440-446`) reads *relationship
properties* — `r.partition`, `r.relationship_key`, `r.relationship_type` — and a
Fluree Cypher relationship over plain RDF triples **has no properties**; only a
reified/annotated edge does. Copying that shape produces `all(...)` false for
every path, an **empty reached set**, HTTP 200, and no error. It is not covered
by Fluree's "clear error, never a silently wrong result" promise, which is about
parse-time rejection of unsupported *forms*. Compounding it, the only admissible
bounded variable-length pattern is a **single fixed relationship type**: bounded
type-alternation (`-[:A|B*1..3]-`) and undirected-untyped (`-[*]-`) are both
documented as deferred. So on plain edges neither the crossability cut nor the
type cut is expressible.

The resolution, which is Mongo's move in a different physical model: **move the
information onto node properties and reduce every hop predicate to membership in
a set the adapter already computed.** Interposition uses only mechanisms that are
old, plain and heavily exercised — subjects, node properties, one predicate,
membership tests. The alternative (edge annotations) is second choice on four
counts, chief among them that RDF-1.2 edge annotations landed in v4.1.0 and the
Cypher front-end in v4.1.1, making it the *youngest* surface in play.

**This plan is complete whether or not stage 2 promotes.** D-07 rung 2 is
pre-costed here, in the plan's own text: if F-A3(a) or (b) fails, ship stage 1,
record a `DI-15.3-NN` deferred item, and hand plan 15.3-05 a gate package
describing a stage-1 adapter. Mongo established that a stage-1 degrade satisfies
the requirement; SUBQ-12's hedge is what makes that a completed task rather than
a failed one. **Rung 3 — STOP and raise a `D-IMPL` — fires only if the finding
would change what `as_of` MEANS on this substrate, not merely how it is
expressed.** A traversal that runs in process instead of in the engine changes
*where* `as_of` is computed, never *what it means*; that is rung 2, always.

Output: F-A2/F-A3 evidence, the interposed walk (or a recorded stage-1 posture
plus a deferred item), depth 0/1/2/3 doubling assertions, and the four-trap-shape
telemetry proof.
</objective>

    1. **Walk fragments.** Replace the Neo4j walk block with the interposed form.
       The pattern is `MATCH p = (seed:CcfEntity)-[:CCF_LINK*1..M]-(x:CcfEntity)`
       with `WHERE seed.ccf_admit_key IN $starts AND all(n IN nodes(p) WHERE
       n.ccf_admit_key IN $admissible)` and
       `RETURN DISTINCT x.ccf_entity_uri AS entity_uri`.
       - **One predicate on both legs.** `CCF_LINK` and nothing else. A two-type
         shape such as `HAS_EDGE`/`TO` would require the deferred bounded
         type-alternation and reintroduces the very constraint being escaped —
         this was explicitly considered and rejected; state that in the fragment's
         `#:` block so a future reader does not re-derive it.
       - **`M = 2 * depth_limit`.** The graph is bipartite (entity–edge–entity),
         so parity handles itself once the terminal is labelled `(x:CcfEntity)`
         and only even-length paths end at an entity.
       - **No direction doubling.** Cypher's `-[:T]-` is first-class undirected;
         Mongo needed doubling because `$graphLookup` is directed. The interposed
         model is written once — strictly cheaper than the Mongo write path.
       - **One parameter list.** `$admissible` is computed **in Python** as
         `{"e:" + uri for uri in survivors ∩ allowed} | {"r:" + key for key in crossable}`.
         The `e:`/`r:` prefixes disambiguate the two namespaces so an `entity_uri`
         can never collide with a `relationship_key`. Crossability — type,
         temporal, policy, validity, `allowed_entities` on both endpoints,
         endpoint closure — is **already fully decided** by the edges statement
         that computes `$crossable`; the walk re-states nothing.
       - **Reject secondary "shortcut" relationships outright.** Hop admissibility
         is membership in the already-computed set, never a re-derivation, because
         a re-derivation is a second place for the semantics to live and the two
         would eventually disagree (`backends/mongo.py:862-873`).
       - **Read no relationship property anywhere.** `grep` for
         `relationships(p)` in this module must stay at 0.
