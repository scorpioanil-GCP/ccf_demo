## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| skill catalog → agent capability | A grant is what turns an offer into a capability; the policy regime bounds what may be granted. |
| human → workflow state | An approval changes what the system does; an unrecorded approval is an unauditable decision. |
| artifact version → replay | Replay resolving "latest" instead of a pinned version silently answers a different question. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-11-01 | Elevation of privilege | skill grant exceeding the policy regime | mitigate | The Control Plane compatibility check refuses a grant whose declared requirements exceed the agent's regime; the refusal **fires in the run** and is asserted as a typed refusal plus an audit-log entry, not as an absence of effect. |
| T-16-11-02 | Repudiation | human approval | mitigate | Audit-by-construction: there is no path through the HITL surface that produces an unrecorded human action (CLAUDE.md §8.2). Asserted on the approver identity and the Context Product the approver saw, both present in the replay record. |
| T-16-11-03 | Repudiation | skill-set at decision time | mitigate | Replay dimension 4 carries the skill-set **in force**, so a decision replays against the skills the agent actually had, not the skills it has now; the test asserts the historical set specifically. |
| T-16-11-04 | Tampering | replay resolving "latest" | mitigate | Replay resolves exact artifact versions; a bumped version changes the outcome visibly, and `grep` for a "latest" resolution returns nothing. |
| T-16-11-05 | Information disclosure | prompt text in code | mitigate | Instruction bindings are **references** to a `ccf.prompt-artifact`; `cinv01a/b/c` rejects prompt-shaped string literals across `src/`, `runtime/`, `examples/` **and `tests/`**. |
