<objective>
Publish Section 3's agentic-skills half and move the eight pages that source from
`examples/01`, `02` and `05` onto the new suite — **without deleting anything**,
so `make docs-strict` cannot go red.

Purpose: this is the phase's largest re-cut, and it is deliberately separated
from deletion. Those three examples all appear in
`tutorial/adopters-guide.md`'s dependency row, which makes their deletion
terminal-wave work (plan 16-18). Re-pointing a page at a new example while the
old one still exists is safe; deleting an example a page still points at is a
hard build error. Doing the re-cut here means plan 16-18 only deletes.

Six of the eight pages are `reference/artifacts/*` — one include each, the
authoring API an adopter actually works against. Two are how-tos with 14 and 6
includes plus prose references. All eight get the same treatment.

The section's prose also carries the sentence Section 3 most needs and is most
likely to omit: every module under `src/ccf/agents/` is `__ccf_mode__ =
"algorithmic"`, and CINV-03 bars a tagged module from importing `ccf.llm` or any
vendor model SDK. **The SDK's agent surface is structurally forbidden from
calling a model.** These agents demonstrate agents as governed identity, not as
reasoners. Without that sentence the section reads as a Mode-2 promise the fabric
does not keep until Phase 17.

Output: one new tutorial page, eight re-cut pages, nav, nothing deleted.
</objective>
