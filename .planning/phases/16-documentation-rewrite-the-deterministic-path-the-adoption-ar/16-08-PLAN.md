<objective>
Teach `λ_c` and `D_c` agent-free, so Section 1 covers the temporal and
staleness half of the fabric and the adoption argument's *"no staleness
measure"* claim has a worked demonstration rather than an assertion.

Purpose: half-life and Context Debt are today taught only inside
`examples/01-agent-basics`, which retires under `D-07` and which is agent-first —
exactly the framing criterion 2 forbids from Section 1. The mechanism itself is
not agent-shaped: `ccf.halflife.decay` computes freshness from a
`ccf.half-life-table` artifact with `decay_driver` and `supersession_event` rows,
and `ccf.halflife.debt` computes `D_c` against a declared debt profile, gating
Forced-LLM / Fail-Closed routing. `D-05` confirms the signal side is already
right: temporal signal is authored as an L1 observation stream, as today, and
the FIBO stores holding static entity state is not a gap — L1 is signal, L3 is
state.

Without this example, `public/reference/protocols/halflife-and-debt.md` has no
worked example to point at, and RESEARCH § E's fourth adoption-argument claim
loses its cited mechanism.

Output: a second Section-1 example, same split, same marker set, sqlite only
(the matrix runner is `s1-01` — `D-06` asks for **one** parameterized runner,
not for every example to be one).
</objective>
