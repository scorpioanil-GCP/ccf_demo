<objective>
Build the phase's reference example: deterministic, agent-free KYC/UBO Context
Product assembly, with the **CCF call spine physically separated from deployment
code** into distinct modules.

Purpose: this is the phase's north star, in Dave's own words —
*"I can't tell from looking at the code which code is example code and which code
is required by the CCF."* `D-11` answers it structurally rather than with a
docs-layer legend, and the test of the answer is whether someone reading the
**repository** — not the rendered site — can see the boundary. Every other
example in the suite copies this one's shape, so getting it right here is worth
more than getting it fast.

It is also criterion 2's whole mechanism: Section 1 is agent-free **by
construction**, so the agent-first mental model UAT gap G-01 condemned cannot
survive the new structure (`D-12`). And it is the KYC/UBO spine (`D-03`) — the
domain where the FIBO data lives and where the UBO question earns a typed
product.

Output: two modules, a thin driver, ~16 artifacts, a seven-heading README, and
three test modules — one for the example's output, one proving it invokes no
agent, one proving the spine/deployment separation holds.
</objective>
