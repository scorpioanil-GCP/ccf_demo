## Q1 — What is a dangling endpoint?
| Option | Description | Selected |
|---|---|---|
| a | A legitimate graph member | |
| b | An unresolved reference — legal persisted state, not a traversal member | ✓ |
| c | Malformed state, an invariant failure | |
**User's choice:** b. **Notes:** preserves the first-class-edge model without pretending an edge assertion creates an entity assertion.

## Q2 — Membership needs a claim, or an edge suffices?
| Option | Description | Selected |
|---|---|---|
| a | A node exists for traversal only when the view holds its entity claim | ✓ |
| b | An edge alone establishes it | |
**User's choice:** a. **Notes:** invariant recorded — "Edges may reference unresolved entities, but traversal operates over claimed entities."

## Q3 — If admitted, what evidence?
| Option | Description | Selected |

**User's choice:** not admitted. **Notes:** "would manufacture context the source never asserted … worse than the current divergence."
