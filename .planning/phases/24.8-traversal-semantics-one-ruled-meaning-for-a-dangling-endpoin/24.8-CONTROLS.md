# Phase 24.8 — Merged-tree controls (G-28)

**Purpose.** Criterion 22 requires the close record to re-measure every criterion **on the shipped
tree**, with the command, the verbatim output and a control for each. Criteria 18, 19, 20 and 21
are all "does not move" claims, and a claim that something did not move is only worth what its
instrument is worth. This file is the measurement half: batches and gates in § Batches, and one
section per "does not move" criterion after it.

**Rules of the record.** Every figure below comes from a command run in the session that wrote the
section it sits in, with the command and its output pasted verbatim. Nothing is copied from a
`*-SUMMARY.md`, from `24.8-LEGS.md`, or from the orchestrator's own pre-measurement — where the
orchestrator had already measured a figure, it was **re-run here**, and where this file's number
differs from anyone else's, the difference is stated rather than reconciled away. Every count
carries a **positive control**: a second command that produces a *different* number, so an
instrument that has silently stopped looking cannot pass as a measurement. Every "empty" claim is
a **pasted empty output**, never a sentence asserting emptiness. Rosters are node ids or file
paths, never bare cardinalities.

**What this file does NOT do.** It edits no source, no test, no example, no generated document and
no tracking file. Its only writes are itself and `24.8-LEGS.md` § After.
