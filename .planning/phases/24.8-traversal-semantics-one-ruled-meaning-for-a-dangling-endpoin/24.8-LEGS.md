# Phase 24.8 — Leg observations and base measurements (G-28)

**Purpose.** Criterion 21 is empirical: *the legs run once at Wave 0 and once at the gate show the
SAME xfail/skip roster for `tests/examples/` by node id*. That set-equality needs a baseline half,
and this file is it. Criterion 13 needs to know which legs were actually reachable at the base.
Criterion 2 needs the citation-anchor numbers the 1.3.0 amendment's line-neutrality is judged
against. **Every later section of this file is a diff against § Baseline** — a red present here is
a pre-phase red (environmental or in-tree at the base) and is never attributed to 24.8; a red
absent here and present later is 24.8's, to be classified under `D-IMPL-261`.

**Rules of the record.** Every count comes from a command run in the session that wrote the
section, with the command and its output quoted verbatim, and **with a positive control** — a
second command that would have produced a different number, so a silently broken instrument
cannot masquerade as a measurement. Rosters are node ids, never counts (a right count with a
wrong member audits clean forever). A scoped count is shown against a scoped denominator.
Nothing is copied from `24.8-RESEARCH.md`; where RESEARCH's *reasoned* rosters are cited, they
are cited to be **compared** against collection, and the comparison result is stated. A leg that
cannot be reached is recorded `NOT MEASURED` with the error verbatim — never as passing, never as
a red. No source, test, example, generated doc or tracking file was touched to produce any
section.
