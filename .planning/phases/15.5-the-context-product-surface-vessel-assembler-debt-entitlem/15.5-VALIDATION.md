## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `pytest` (via `make test`, `CCF_REQUIRE_HARNESSES=1`) |
| **Config file** | `pyproject.toml` `[tool.pytest]`, `testpaths = ["tests"]`; separate `perf/pytest.ini` for the battery |
| **Type gate** | `mypy --strict` over `src` + `runtime` (`make typecheck`) |
| **Lint gate** | `make lint` → `tools/lints/` (CINV-01 no-hardcoding, CINV-02 harness imports, CINV-03 `@algorithmic`, substrate names, orchestration split) |
| **Quick run command** | `PYTHONPATH=src:runtime .venv/bin/python -m pytest tests/products tests/gates tests/replay -x -q` |
| **Full suite command** | `make ci-core` mid-phase; `make ci` at any wave touching `examples/` or `public/` |
| **Perf command** | `make perf-micro` — **not in `ci`**, must be run deliberately (10% relative-median gate) |
| **Estimated runtime** | quick ~15 s · `ci-core` ~7 min · `ci` ~12 min |

**Interpreter warning.** Bare `python3 -m pytest` fails collection with
`ModuleNotFoundError: No module named 'ccf'`. Worktrees have no `.venv` (it is
gitignored) — symlink it before the first verification command.

---

## Sampling Rate

- **After every task commit:** quick run, plus `make lint` on any `src/` touch.
- **After every plan wave:** `make ci-core`. Add `make ci` when the wave touched `examples/` or `public/`.
- **Per baseline-touching plan:** `make schemas` / `make openapi` / `tools/dump_surface.py --report` plus its fragment, **in the same commit** as the change.
- **Before phase gate:** `make ci` green, `make perf-micro` inside band, `tools/retirement_sweep.py --report` diffed.
- **Max feedback latency:** ~15 s per task; ~7 min per wave.

**CPS-11 is the phase's most important test and it already exists.**
`ReplayEnvironment.rehydrate_product` rebuilds the product from the record plus
the re-executed projection, and `engine.py:449-453` raises `ReplayDivergence`
when the reproduced content address differs from the recorded one. Any field
added to `ContextProductContract` must therefore be reconstructible from the
record, the product class, or the projection output. Debt is none of those.
**Run CPS-11 against every candidate debt placement before committing to one.**
