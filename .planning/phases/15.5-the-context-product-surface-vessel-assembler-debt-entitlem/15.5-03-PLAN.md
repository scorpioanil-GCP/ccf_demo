## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deployment-authored artifact → the fabric | A deployment authors the entitlement policy; the contract's shape must make a permissive default unreachable |
| Control Plane registry → the door | The door (plan 15.5-06) reads this artifact per call; a cached or defaulted grant would be an authorization bypass |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15.5-07 | Elevation of Privilege | `ProductEntitlementGrant` field set | mitigate | `extra="forbid"` plus the field-enumeration test asserting no name matches the forbidden-marker set; a docstring cannot fail when someone adds `unrestricted_principal` |
| T-15.5-08 | Elevation of Privilege | `grant_for` on an unconfigured principal | mitigate | Raises `PrincipalNotEntitled`; never returns a permissive empty grant. Deny-by-default matches the shipped `ControlPlaneTenantAuthorizer` posture (T-10-01) |
| T-15.5-09 | Information Disclosure | cross-tenant grant leak | mitigate | `tenant_id` is a field on the artifact, so two tenants hold two artifacts with two content addresses — no shared object to leak through. Asserted by the two-tenant test |
| T-15.5-10 | Spoofing | caller-asserted role | mitigate | `permitted_roles` on the grant plus `require_role` raising; this plan supplies the mechanism, plan `15.5-06` binds it at the door before `Perspective` is constructed |
| T-15.5-11 | Repudiation | schema drift between contract and committed schema | mitigate | `make schemas` runs and commits in the same commit as the contract; the bytes-equality gate in the always-on `test` job is the enforcement |
| T-15.5-SC | Tampering | npm/pip/cargo installs | accept | No package is installed — `15.5-RESEARCH.md` § Package Legitimacy Audit records that this phase adds no dependency |
