## Deviations from Plan

**1. [Rule 3 — Blocking] The tripwire runs in a separate interpreter, not
in-process.** The plan says "run `pytest tests/replay/test_engine_rehydration.py`
in-process". Implemented as `subprocess.run([sys.executable, "-m", "pytest", …])`
instead. A nested `pytest.main()` inside a live session shares the outer run's
capture, plugin registry and already-imported conftest modules, so a red result
could be an artifact of two sessions interacting rather than a fact about the
tripwire — which would corrupt the very figure the leg exists to produce. The
measurement is identical and takes ~1.1s. Guarded by `CCF_SPIKE_RUN_TRIPWIRE`
so the leg is switchable without editing the module. Commit `f000e28`.

**2. [Rule 2 — Missing critical functionality] The `serve` count is split into
bare-name and attribute calls.** A single count would have merged
`server.serve()` (an unrelated method) into the governed-delivery-seam figure
and overstated the in-process population Q3's fourth option reaches — 32 rather
than 18. Since that figure is quoted directly in the ruling package, an
overstated version is a defect in the evidence, not a rounding issue. Commit
`f000e28`.

**3. [Rule 2 — Missing critical functionality] The A8 figure is read from
`perf/gate.py`'s results file rather than the raw benchmark output.** The raw
file carries medians but not baselines, so a relative delta and an absolute
margin — the two things the ruling needs — could not be computed from it. The
gate's own results file carries `baseline_median`, `median` and `threshold` per
benchmark. Commit `8d518f6`.
