<what_may_be_imported — read before writing a line>
This test uses cp-05 as a **source of declarations and extension points**. The fence permits it in
terms: *"cp-05 declarations and measured estate behavior may be used as test inputs."* Importing
is reading. But **what the harness has to take from cp-05 is the measurement**, so the roster is
partitioned rather than merely listed.

**Permitted, and each import is classified when it is made:**

- The YAML documents (`ccf_config.yaml`, `artifacts/replay.yaml`, `artifacts/question.yaml`,
  `artifacts/ttl.yaml`). Always **declarations** — the class the SDK expects a deployment to
  author.
- `projection.py`'s plan construction, wired as `plan_factory`. **Extension point** — Dave names
  `plan_factory` as one by name.
- A debt scorer, if cp-05 declares one. **Extension point** — Dave names it by name.
- The reconciliation predicate, wired as `product_gate`. **Extension point as of wave 2** — that
  is what `R-11` was for, and if it is *not* wireable, that is a finding against `R-11`.
- `deployment.py`'s declaration-loading helpers (`load`, `register_class`, `effective_request`).
  **Classify each on its merits.** A helper that only reads a document and hands it to an SDK
  registration call is an adopter convenience. A helper that reconstructs governance the SDK
  should own is **rebuilt fabric behavior** — and that is a finding.

**Forbidden, and each is a finding if the test cannot proceed without it:**

- `produce.py`'s hand-composed spine — `ProjectionEngine` → `run_gates` → `build_replay_record` →
  `serve`. **That composition is precisely what this test asserts `GovernedResolver` replaces.**
  If the test cannot reach a served product without borrowing a limb of it, stop: name the limb,
  measure it, classify it `24.10-F-NN`, and that is terminal state B.
- Any write into `examples/`. Not one byte.

**The partitioned roster goes in the SUMMARY**, as a table: module, what was taken, and
`extension point` or `rebuilt fabric behavior`, with one sentence of reasoning each. **The second
column of that partition is the stop rule's answer.** A roster with everything in the first
column and a served product at the end is terminal state A; anything in the second column is
terminal state B, whether or not a product came back.
</what_may_be_imported>
