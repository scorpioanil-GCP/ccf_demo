<objective>
Widen every gate that decides whether the archive is looked at — while the
archive does not exist, so each widening is a strict superset that changes
nothing measurable and can therefore be proven in isolation.

Purpose: this is `D-05`'s principle applied to every tool at once. A bare move
leaves **265 files — including 96 Python modules — outside the scope of every
CINV lint**, and `python -m tools.lints --all` was measured EXITING 0 with the
trees moved, because it stopped looking. It leaves four count floors and the
citation walk red, and the collected total down 69. And it leaves 216 `$schema`
headers rotten with the gate that checks them reporting CLEAN, because its glob
finds nothing in the archive. Every one of those is a tool that reports clean
because it did not look — the exact defect Phase 22.1 was commissioned to fix.

Doing this BEFORE the move is what lets Wave 4's move be the only thing under
test. It also means every widening's proof is *"the tree was green before and
is green after"*, which is a proof a later reader can re-run.

Output: seven constants and one glob that reach the archive, each with a
membership assertion beside it.
</objective>
