## Verified BLOCKING findings — one family: values the SDK accepts but should refuse

All four are the same defect class, and the phase itself already contains the
correct pattern in one place. `SignalObligation` (plan `15.6-08`) namespaces its
sentinel `ccf.no-obligation-in-force`, **refuses that spelling as a declared
value**, and **refuses blank/whitespace refs**. The three siblings do not.

### B1 — `Observation.subject`'s sentinel spelling is neither namespaced nor reserved
*Raised independently by Codex (HIGH) and Cursor (MEDIUM). Confirmed by execution.*

`NO_SUBJECT_IDENTITY: Final[str] = "no-subject-identity"` — a bare string, not
`ccf.`-prefixed — and `Observation` carries no validator refusing it as a declared
subject.

```
Observation(..., subject=NO_SUBJECT_IDENTITY).subject == Observation(...).subject
  ->  True
```

A deployment whose real opaque subject is spelled `no-subject-identity` produces an
artifact **indistinguishable from an omitted subject**. That is precisely the state
`D-IMPL-120` exists to prevent: *"an omitted identity and a dropped one are not the
same artifact."* Fidelity defect against a ruling made **this phase**.

Fix: namespace the sentinel and add the reservation validator `SignalObligation`
already has.

### B2 — `DebtEvidencePointer.handle` accepts blank and whitespace
*Cursor (MEDIUM). Confirmed by execution.*

```
DebtEvidencePointer(handle='')     -> ACCEPTED
DebtEvidencePointer(handle='   ')  -> ACCEPTED
```

Validation is float-refusal, uniqueness and canonical ordering — no blank refusal —
while `SignalObligation.obligation_ref` refuses blanks for exactly the
"declared nothing vs not declared" distinction. A blank handle is a pointer that
points at nothing wearing the costume of one that does. Violates CLAUDE.md §11
*"validation is at the boundary, never deferred."*

### B3 — `ContextProductContract.obligation_in_force` is unvalidated on the vessel
*Codex (MEDIUM). Confirmed by inspection — `contract.py:671`, no validator.*

The profile side refuses blanks and the sentinel; the vessel field is a bare
`str = NO_OBLIGATION_IN_FORCE`. A product constructed or rehydrated with `""`
carries a third state — neither "no obligation bound" nor "deployment-declared
obligation" — and because the field is inside the content address, that ambiguous
value becomes **replay-stable product state**.

### B4 — the anti-vocabulary invariant misses tuple-shaped tables
*Cursor (LOW — raised to blocking here). Confirmed by injection.*

`tests/invariants/test_no_obligation_vocabulary.py` refuses `Enum`/`StrEnum`/
`IntEnum` classes and `Literal[...]` over string constants, reading annotations as
well as values. It does **not** see a closed table in tuple form. Injecting

```python
_OBLIGATION_TABLE: tuple[str, ...] = ("re-pull", "escalate", "fail-closed")
```

into `src/ccf/halflife/debt.py` — inside the guard's own scan root — leaves the
suite **green (14 passed)**.

This matters more than its LOW rating suggests. The guard is the phase's
highest-value Wave-1 artifact, built specifically because a three-member obligation
vocabulary passes every other lint in the tree and is still the CLAUDE.md §11
defect. A tuple is the most natural alternative spelling of the exact thing it
exists to refuse.

## Advisory findings

### A1 — a zero-span refresh window is a residual cardinality signal
*Cursor (MEDIUM). Confirmed: `oldest == newest` is accepted by design.*

`D-IMPL-124` removed source identities **and count**. Equality is explicitly legal
("one source, or several that published together"), so a consumer seeing
`oldest == newest` learns the declared set is size 1 **or** fully synchronised —
aggregate enumeration without names. Not a reopening of the per-source channel;
a residual edge the ruling's "no count" spirit does not fully kill. Single-source
deployments publish a zero-span window by construction. **Dave's call whether
Shape B is tightened.**

### A2 — the deferred cache retains `GraphView` references for the whole execution
*Cursor (MEDIUM). New consequence of `15.6-02`'s change, not previously recorded.*

`_Deferred(operator, view, upstream, output)` holds the view until the cache dies.
Previously `run()` hashed the view and stored only `OperatorOutput`, retaining no
view after return. Hit correctness is unchanged; **peak retention during an
execution rises**, and since `ProjectionEngine.execute` invokes each key once, the
deferred list never drains via lookup. Interacts with the unclaimed
`perf/baselines/local.json` re-baseline — a memory delta baselines will not catch
until remeasured.

### A3 — `CanonicalizationError` now surfaces later
*Codex (MEDIUM). Confirmed — and **already recorded** in
`docs/surface-changes/15.6-02-intermediate-cache-key.md`, in almost the same words.*

Not a new finding. The panel independently rediscovered a documented, reasoned
narrowing, which is evidence the fragment is accurate rather than evidence of a
defect. No action.

### A4 — the new citation ratchet floors inherit the coupling-tree hazard
*Cursor (LOW). Already open as `DI-15.6-02`.* No new action.

### A5 — docstring cross-reference drift in `fluree.py`
