## Sampling Rate

- **After every task commit:** `PYTHONPATH=src:runtime .venv/bin/python -m pytest tests/halflife tests/products tests/replay -x -q` (~6 s), **plus `make lint` on any `src/` touch**.
- **After every commit that changes a hashed contract:** `pytest tests/replay/test_engine_rehydration.py -q` — **before the first edit and after every such commit**. This is `D-IMPL-100`'s own instruction to plan `15.5-11`, restated because **plans `15.6-05` through `15.6-08` (Waves 3–6) each move a hashed contract, and `15.6-06`, `15.6-07` and `15.6-08` each move the product content address.**
- **After every plan wave:** `make ci-core`. **`make ci` where the plan's own gate says so** — plans `15.6-03` (Wave 1), `15.6-05` (3), `15.6-06` (4), `15.6-07` (5), `15.6-08` (6), `15.6-10` (8), `15.6-11` (9) and `15.6-12` (10). Only `15.6-01`, `15.6-02` (Wave 1), `15.6-04` (2) and `15.6-09` (7) close on `make ci-core`; every one of them is documentation- or `tools/`-scoped. **The plans are the binding statement here — where this list and a plan disagree, run the plan's gate.**
- **Per surface-touching plan:** its `docs/surface-changes/` fragment **in the same commit** as the `src/` change, plus `make schemas` where a docstring moved. `.venv/bin/python tools/dump_surface.py` regeneration happens **once for the phase**, in plan `15.6-10` task 2, after the last Track B `src/` edit; every earlier plan asserts `git diff --exit-code docs/surface/v0.2-surface.json` and relies on `tests/test_surface_drift.py`'s documented-drift allowance.
- **Per perf-touching plan:** `make perf-micro CCF_PERF_RUNNER_CLASS=local` ×3 (plan `15.6-02`).
- **Before `/gsd:verify-work`:** full suite green.
- **Phase gate:** `make ci` exit 0 · `make perf-micro` inside band · `perf/baselines/local.json` unmodified · `python -m tools.lints --report` recorded · then the CLAUDE.md §3.1 close sequence (cross-AI panel `--all` against shipped code → single-agent review → verify every finding → fix blocking in-phase → present to Dave). Owned by plan `15.6-12`.
- **Max feedback latency:** ~6 s per task · ~7 min per wave · ~8 min at any `make ci` boundary.
