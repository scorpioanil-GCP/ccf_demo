## Sampling Rate

- **After every task commit:** `PYTHONPATH=src:runtime .venv/bin/python -m pytest tests/halflife tests/products tests/replay -x -q` (~6 s), **plus `make lint` on any `src/` touch**.
- **After every commit that changes a hashed contract** (every Wave-3 commit): `pytest tests/replay/test_engine_rehydration.py -q` — **before the first edit and after every such commit**. This is `D-IMPL-100`'s own instruction to plan `15.5-11`, restated because Wave 3 has three plans that each move the product content address.
- **After every plan wave:** `make ci-core`. Add **`make ci`** on any wave touching `examples/`, `public/`, `Makefile` or `mkdocs.yml` — Waves 1, 3 and 5.
- **Per surface-touching plan:** `.venv/bin/python tools/dump_surface.py` + `make schemas` + its `docs/surface-changes/` fragment, **in the same commit**.
- **Per perf-touching plan:** `make perf-micro CCF_PERF_RUNNER_CLASS=local` ×3.
- **Before `/gsd:verify-work`:** full suite green.
- **Phase gate:** `make ci` exit 0 · `make perf-micro` inside band · `perf/baselines/local.json` unmodified · `python -m tools.lints --report` recorded · then the CLAUDE.md §3.1 close sequence (cross-AI panel `--all` → single-agent review → verify every finding → fix blocking in-phase → present to Dave).
- **Max feedback latency:** ~6 s per task · ~7 min per wave · ~8 min at any `make ci` boundary.
