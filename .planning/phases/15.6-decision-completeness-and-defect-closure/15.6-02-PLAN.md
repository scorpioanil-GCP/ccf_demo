## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| perf gate configuration → regression signal | A widened band that widened the wrong benchmark, or a mis-spelled id that widened nothing, silently removes a real regression signal |

| cache key computation → replay determinism | `D-IMPL-36` guarantees a cache hit returns the value recomputation would produce; a key whose composition changed would break that by construction |
