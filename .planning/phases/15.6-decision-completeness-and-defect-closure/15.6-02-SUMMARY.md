- **`behavior`, not `reshaped`.** `IntermediateCache`'s constructor shape is still `() -> 'None'`; `tools/dump_surface.py --report` shows nothing added, removed or reshaped, and `reshaped` fails `tests/test_surface_completeness.py` with no diff line to point at. ## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The plan's literal lazy-key form saves nothing; implemented deferred key materialization instead**

- **Found during:** Task 2
- **Issue:** The plan prescribes "compute the key only when `self._entries` is non-empty. A first insertion still needs a key". Measured against the shipped engine path, that form changes nothing: `ProjectionEngine.execute` builds `operators_by_key` as a dict and calls `cache.run` once per key, so **every call is a miss and every miss inserts** — and insertion needs the key. A fresh cache with *n* distinct operators builds *n* keys either way (1 for the first insertion, *n*−1 for the subsequent probes). Shipping it would have narrowed a ruled contract's witness for zero benefit and failed the task's own acceptance criterion that `test_composed_chain`'s median be lower.
- **Fix:** The key is deferred rather than merely guarded. An intermediate produced for an operator the cache has not seen is held un-keyed in `_Deferred`; the key is materialized at the first call that could hit — a second call for the same `operator.key`, which is the key tuple's first component and therefore a necessary condition for any match. The key expression itself moved verbatim into `IntermediateCache._key`: four components, same order, nothing decomposed, nothing new hashed.
- **Files modified:** `src/ccf/operators/planner.py`
- **Verification:** Probe figures identical before and after (640 engine runs, 0 engine hits, 1 other hit); `tests/operators/test_planner.py`, `tests/properties/test_composition.py`, `tests/conformance/test_similarity_index.py` pass **unmodified** (`git diff --exit-code` on all three exits 0); `test_composed_chain` 0.386 s → 0.176 s; `make lint`, `make typecheck`, `make ci-core` (2887 passed, 81 skipped) green.
- **Committed in:** `f6ac822`

**2. [Rule 3 - Blocking] `docs/SURFACE-CHANGES.md` had to be regenerated, which the plan's file list does not name**
