<interfaces>
Contracts the executor needs. All measured during research against a live door.

**The door's tool.** `request_context_product`, 8 required arguments —
`tenant`, `product_class`, `version`, `request`, `subject`, `intent`, `freshness`,
`asked_at` — plus optional `parameters` (object, default `{}`). Registered at
`runtime/ccf_runtime/mcp/egress.py::request_context_product`. It returns **one**
`TextContent` block of canonical JSON.

**The `request` argument is an opaque string and its JSON Schema is a bare
`{"type": "string"}`.** A foreign client cannot learn its shape from tool
discovery — it must be told. It is the canonical JSON of a three-field
`WireRequest`:

    json.dumps({"product_id": <str>, "parameters": <mapping>, "temporal_boundary": <rfc3339 or null>},
               sort_keys=True, separators=(",", ":"), ensure_ascii=False)

Byte-exactness is not required — the door *parses* the string. `json.dumps` alone
is the whole client-side encode; `json.loads` and print is the whole decode.

**The response** is a JSON document with top-level `content_address`,
`product_json`, `refusal`, `replay_ref` and the echoed `request`. Criterion 4's
content address is a top-level key.

**The payload assertion — criteria 1-3, and the gap an address-only check leaves.**

check in this phase reads a 64-hex string, and a client that printed the content
address and nothing else would pass all of them while criteria 1-3 were false. Add

pair:

    payload_violations(reference_stdout: str,
                       leg_stdout: str,
                       declared_names: Sequence[str]) -> list[str]

It returns a violation when:

  - `declared_names` is empty — a marker search over no markers is a vacuous pass;
  - **no** declared name appears in `leg_stdout` — the leg printed an address and
    not a product;
  - the **set** of declared names appearing in `leg_stdout` differs from the set
    appearing in `reference_stdout` — the leg printed *a* product but not the same
    one, which an equal content address does not by itself rule out for a client
