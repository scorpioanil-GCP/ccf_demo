<objective>
Build the fabric-side runner and prove criterion 4 **with zero client legs
wired**. The runner copies `deployment/` and `server/` into one temp parent,
seeds the copy from the declared input document, closes the writer, resolves the
door's `command + args` from `binding.yaml`, runs `consume.py` against the same
copy, and reports the resulting content address.

Purpose: if the runner cannot produce a real, non-empty content address from a
seeded temp copy, no leg can be *proven* and every later wave is measuring the
wrong thing. This is the gate research named: substrate first, legs after.

Output: `runner/run.py`, one `make` target wired into `examples:`, and a test
asserting that wiring. `make ci` stays green from this plan onward.
</objective>
