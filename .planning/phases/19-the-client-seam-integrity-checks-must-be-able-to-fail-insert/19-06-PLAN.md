## Rulings settled at planning, so they are not re-litigated in execution

1. **Header name: `X-CCF-Request-Echo`.** It follows the existing
   `X-CCF-<Title-Cased-Hyphenated>` convention and names what it *is*, matching
   `check_outcome`'s vocabulary of "the echo".
2. **Header value: base64url of the canonical bytes**, with the reasoning recorded in the
   constant's comment. `wire.py:50-53` rejects a second rendering **of the vessel**, and
   that argument does not transfer: it was about the content address becoming a function of
   the envelope, and nothing hashes the echo. Header-safety on every intermediary is a real
   property, and canonical JSON contains `"` and may contain non-ASCII. Use
   `base64.urlsafe_b64encode(canonical_bytes(asked)).decode("ascii")`; a future HTTP
   adapter decodes it and never reconstructs from its own state — write that sentence
   down, because it is the whole of `C-09`.
3. **No OpenAPI declaration.** Measured: `grep -c "X-CCF" openapi.json` returns **0** —
   neither existing sibling header is declared, so declaring the third would make the
   committed schema inconsistent with itself and would put a `make openapi` regeneration in
   a wave that does not need one. Follow the precedent; record that the precedent was
   measured, not assumed.
4. **`canonical_response`'s new parameter is keyword-only with a `None` default**, exactly
   like `replay_ref`. The four non-product call sites (`agent.py:74`, `config.py:98`,
   `replay.py:47`, `replay.py:65`) pass nothing and are untouched. The docstring's
   enumeration of five call sites at `:189-192` must be re-read and re-counted if that
   number moves.
5. **When `_asked` returns `None`, no header is stamped.** On the identical reasoning
   `REPLAY_REF_HEADER` already carries at `:64-66`: *"Stamping an empty header would make
   'no record was named' and 'the record is named by nothing' the same observation."*
6. **The HTTP echo's `temporal_boundary` is never `None` when the header exists**, because
   the HTTP door requires `asked_at` whenever any axis is supplied. That asymmetry with
   `mcp+stdio` is a property of the transports and is recorded in one sentence, not
   engineered away.
7. **`C-18`'s temporal cross-check has no subject on this door, and that is a measurement
   rather than an exemption.** `C-18` closes a gap that exists wherever the instant crosses
   a boundary **twice** — inside the encoded request and again as a separate `asked_at`
   argument. Here the echo's `temporal_boundary` is built **from** `asked.asked_at`, the one
   value the route itself parsed, so there is exactly one source and a cross-check would
   compare a value with itself. Record that in one sentence beside the echo construction, so
   a later reader does not read the absence as an oversight. Nothing about `C-18` is
   implemented in this plan.

## The one thing this plan must MEASURE before it commits to a shape

`WireRequest` refuses a parameter value that would not survive the wire — a `float`, a
`Decimal`, a `set`. HTTP `parameters` arrives as a JSON string, so a caller **can** send
`{"x": 1.5}`, and today the door forwards it verbatim to the resolver. Building the echo
would refuse it at construction.

**Measure first**, before writing the branch: send a float parameter to the product route
on the current tree and record the status and body; then decide between the two shapes
below and record which and why.

- **Default, and what to do unless the measurement says otherwise:** let the refusal become
  a `400` carrying the existing product-parameters-malformed error code, with the guard's
  own message naming the wire-stable spelling. That is `D-08`'s posture — the fabric never
  silently degrades a caller's value — and it makes both doors refuse the same class of
  value, which is what `tests/mcp/test_egress_parameters.py::assert_same_verdicts` holds
  them to.
- **If that breaks `assert_same_verdicts`**, stop and report the divergence with the
  measurement rather than loosening either door.

Publishing no header for a question that cannot be represented is **not** an option: a
sibling that silently disappears for some questions is the pattern `C-10` names.
