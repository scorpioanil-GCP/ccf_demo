## Rulings settled at planning, so they are not re-litigated in execution

1. **The hostile adapters live in `tests/client/conformance/`, never in
   `src/ccf/client/adapters/`.** A module under the shipped adapters directory registers a
   scheme at import (`SCHEME_REGISTRY[SCHEME] = …`) and would become a shipped adapter and
   drift the public-surface manifest.
2. **A hostile adapter SUBCLASSES or WRAPS the shipped adapter; it is never written from
   scratch.** `test_the_mcp_binding_fires.py:9-16` and `test_codec.py:7-12` both state the
   rule: a control that tests a copy proves only that the copy fires.
3. **Assert on the discriminating message, never on a digest value.** `match="different question"`
   for the echo and `match="content address"` for the address. Both strings already exist
   in `codec.py`. Asserting a digest would make the control restate the implementation.
4. **Assert the exact `D-10` type.** `TransportError`, not the `BindingError` subclass.
   Where the distinction matters, assert `type(exc) is TransportError`.
5. **A caught crossing produces NO `Result` at all** — not a refusal. Assert that the
   `with pytest.raises(...)` block produced no value, in the shape
   `assert_wire_failure_parity` already uses for the same distinction.
