## Sampling Rate

- **After every task commit:** run the module(s) the task named in `<automated>` (quick run command).
- **After every plan wave:** the four chunks in the foreground plus the two store legs; `tools/check_product_gates.py`; `make lint`; `make typecheck`; `make gate-tools`.
- **Before `/gsd:verify-work`:** full suite green except reds carved by a dated ruling; `docs/surface/examples/RETIREMENT-COUPLINGS.md` regenerated LAST.
- **Max feedback latency:** 120 s per task (one module).
