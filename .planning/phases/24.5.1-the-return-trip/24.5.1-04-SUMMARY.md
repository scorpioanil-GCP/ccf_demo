## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The negative comparison's `disagree` branch was unreachable as specified**
- **Found during:** Task 2, writing the controls.
- **Issue:** the plan orders "any stdout without a `REFUSED` match → no refusal line" (exact regex) BEFORE "the set of refusal lines larger than one → disagree"; two legs that both match an exact regex can never differ, so the named control "two different refusal lines → disagree" could not be satisfied.
- **Fix:** each leg is read for ANY `refused: …` line first (`ANY_REFUSAL`), the `— None` check and the disagreement check follow, and the agreed line is finally required to fullmatch `REFUSED` (violation "does not name `empty-operator-result`"). All plan-named strings are reachable; a seventh control covers the new branch.
- **Files modified:** `tests/examples/test_hw1_empty_fabric_refusal.py`
- **Commit:** `3f1b4d9b`

**2. [Rule 3 - Blocking] `tools.docs_tests._prose.paragraphs` cannot serve byte equality**
- **Found during:** Task 3. `Paragraph.raw` is whitespace-collapsed by design (`_emit` joins with spaces and `_collapse`s), so the plan's "use `paragraphs` if its import is clean" would have compared collapsed text.
- **Fix:** the test imports that module's `_FENCE_RE` (same fence definition) and extracts the fence lines verbatim itself.
- **Files modified:** `tests/examples/test_hw1_readme_expected_output.py`
- **Commit:** `cb4427c5`

**3. [Scope] `seed.py`'s "into <DEPLOYMENT relative to repo root>" print** falls back to the absolute path when the deployment is not under the working directory (a copied example in `tmp_path`), instead of raising `ValueError` from `relative_to`. Commit `8f98ec04`.
