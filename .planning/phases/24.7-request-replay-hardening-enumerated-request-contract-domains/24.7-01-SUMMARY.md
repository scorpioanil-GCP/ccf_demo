# Phase 24.7 Plan 01: The request contract declares an enumerated domain Summary

`ArgumentDomain` now states numeric bounds OR a closed member set, exactly one; membership is exact typed equality through one judgment shared by the domain step and the contract validator; a miss is the ninth reason `not-in-domain`, returned as data with the allowed set riding only in `detail` so `PERMITTED_AT_MINIMAL` governs its exposure with no new row; the field is hash-transparent at `None` and on both rosters; the committed schema and surface follow the class.

## What was built

- **Task 1 (`e22b1cec` RED → `6201f920` GREEN).** `ArgumentDomain.members: tuple[str | int | bool | Decimal, ...] | None`, hash-transparent at `None`. The validator `_at_least_one_end_and_in_order` (name kept) is the one-shape validator: both shapes → ValueError naming `minimum`/`maximum` and `members`; neither → "neither shape"; empty set, non-finite member, heterogeneous set (naming the classes), duplicate (naming the member, judged by the membership rule so `1`/`Decimal("1")` are duplicates and `1`/`True` are heterogeneous). `refuses(value: object)`: numeric shape via `_as_decimal` then the existing two-end judgment (a value with no magnitude → `None`; the payload step owns `type-mismatch`); enumerated shape → `_is_member` over the set → `"not-in-domain"`. `_member_class` (bool first) and `_is_member` are functions, not module-level tables (the guard). Every message cites `D-IMPL-264` beside `D-IMPL-259`; the docstring quotes Q4 verbatim.
- **Task 2 (`f9af7550` RED → `54aba182` GREEN).** `"not-in-domain"` appended LAST to `ProductRequestViolationReason` with its `#:` paragraph; `ProductRequestViolation` docstring → nine ways, and the `detail` contract for a membership refusal. `_refuse_domain` hands the presented value to `domain.refuses` for either shape (no `_as_decimal` pre-filter), keeps sorted iteration, skip-if-not-presented and the type-mismatch-wins order, and builds the violation with `declared_type` = the property's `JsonSchemaType`, `presented_type = type(presented).__name__`, and a `detail` naming key, `repr(presented)` and the sorted members. The contract validator (name kept): `unmeasurable` narrowed to numeric-shape domains; new `mistyped` (`string`→string, `boolean`→boolean, `number`→numeric, `integer`→numeric with every member an `int`, `array`/`object`→never); `contradicted` generalized to `domain.refuses(default) is not None` over either shape, message fragment "outside their own domain" kept; one ValueError names all five classes.
- **Task 3 (`88db700e`, `010d62ba`).** `ccf.products.request.ArgumentDomain.members` appended to `_MARKED_IN_THE_TREE` and `NAMED_SINCE_THE_SWEEP` in the 24.6-14 voice; `make schemas`, `make surface`, `make surface-changes` regenerated and committed; fragment with six sections (seven fields each) opening with "What did NOT change".
