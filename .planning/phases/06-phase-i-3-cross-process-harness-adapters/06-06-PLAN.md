Complete the L1 half of XPRC-01's MCP client leg — ingress normalization — plus `mcp` skill
dispatch, so the transport wave arrives end-to-end rather than as a library with no
consumer (D-05). The L4/L5 decision-time acquisition leg is its sibling plan 06-17, in the
same wave; the two together bind every consumer of the shared client the requirement names
except the Experience layer.

Purpose: ROADMAP criterion 1 requires client ingress "normalizing to the L1 envelope"
(this plan) **and** the L4/L5 acquisition edge (CLAUDE.md §7.1, plan 06-17). Those are two
different consumers of the one shared client, and only a bound, tested seam discharges
either — a client library existing is not a seam being bound (D-21). The harness skill-exposure seam in wave (c) is separately only meaningful if it
sees all four skill types actually working; the `mcp` binding type has been declared and
typed in `catalog.py` since I.2 while `dispatch.py` raised `NotYetBound`.
Output: `MCPSourceAdapter` + its mapping module, the `mcp` dispatch path, and their tests
including a cross-process ingress proof.

The Experience-layer edge of criterion 1 is **not** in this phase: `06-CONTEXT.md` defers
the Experience Layer front doors (CLI, HTTP API) to Phase 7, and the MCP egress server
built in 06-04 is the L6 half. Plan 06-16 records that deferral as an explicit gate row so
a reviewer reading criterion 1 sees it named rather than missing.

  <action>
Create two modules, splitting transport from mapping exactly as CDC does:

`src/ccf/signal/mcp_envelope_map.py` — a pure `to_envelope(...)` function plus
`McpMappingError`. Implement research Pattern 2's mapping table exactly:
- `source.system_id` ← the deployment-declared system identity for the server. **Never
  the server URL** — the URL is location, not identity (INV-CH8-01). Say this in the
  docstring.
- `ingestion_timestamp` ← the adapter's injected clock (CDC precedent).
- `observed_time` ← `None`. MCP has no observed-time concept; inventing one would be L1
  interpreting. State that as the reason, not as a TODO.
- `raw_payload` ← `contents[i].text` parsed as JSON, or `{"blob": <base64>}` for a
  `BlobResourceContents`. Opaque; the source's vocabulary, not CCF's.
- `source_metadata` ← the MCP-shaped facts `{uri, mimeType, resource_name, _meta}`,
  quarantined out of the payload.
- `tenant_id` ← the keyword-only argument (deployment config), never a constructor field.
- `envelope_id` ← minted by the adapter, per the CDC precedent.
Wrap every failure with which content item failed, in the CDC error-with-position shape.

`src/ccf/signal/mcp_source.py` — `MCPSourceAdapter` implementing `SignalSourceProtocol`:
`source_identity()` and `async def envelopes(self, *, tenant_id: str)`. Keyword-only
constructor taking the system_id, the resource selection, the shared client from
`ccf.mcp.client`, and an injected clock defaulting to the `_utc_now` shape. Because
`SignalSourceProtocol` declares no graph handle, the adapter structurally has nowhere to
put one — this is the same property `CDCSourceAdapter` relies on; restate the argument in
the docstring rather than asserting discipline.

**SSRF control (new threat this phase):** the MCP source server endpoint must come from
Control Plane configuration passed at construction. Neither the endpoint nor any part of
it may be read from a decision-time argument or from a previously fetched payload. State
this as a docstring constraint and enforce it by shape: `envelopes()` takes only
`tenant_id`, and no method accepts a URL.

Both modules are algorithmic (`__ccf_mode__ = "algorithmic"`), carry the house header
with a citation line marking them SDK-defined per CLAUDE.md §7.1 and citing whitepaper
§8.3 Pattern 3, and contain no server names, resource names, or tenant identifiers as
literals.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External MCP source server → L1 Signal Layer | Untrusted third-party content entering the fabric; L1 must not interpret it |
| Skill catalog binding → outbound network call | A binding value determines what host the process contacts |
| MCP client → L2/L3 | Must not exist; ingress reaches L3 only via `worker.ingest` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-24 | Information Disclosure | SSRF via an MCP ingress or dispatch server URL sourced from decision-time input or a fetched payload | mitigate | Endpoints come from Control Plane configuration at construction; no public method accepts a URL at call time; grep- and test-enforced (Tasks 1–3). **New threat this phase** |
| T-06-25 | Tampering | Hostile MCP source content interpreted by L1 | mitigate | Payload lands opaque in `raw_payload`; MCP-shaped facts quarantined in `source_metadata`; `observed_time` is `None` rather than inferred; malformed items raise `McpMappingError` with position rather than being skipped |
| T-06-26 | Information Disclosure | Cross-tenant envelope leakage from one adapter over a shared source | mitigate | Tenancy is a per-call `envelopes(*, tenant_id)` argument, never a constructor field; two-tenant test fails if moved (D-23, INV-CH7-16) |
| T-06-27 (extends T-02-26) | Tampering | `MCPSourceAdapter` acquiring a write handle | mitigate | `SignalSourceProtocol` declares no graph handle so there is nowhere to put one; `inspect.getsource` scan asserts the module names none; every claim reaches L3 via `worker.ingest` |
| T-06-28 | Elevation of Privilege | An ungranted or revoked `mcp` skill reaching the network before its governance check | mitigate | Grant check precedes any transport work; test asserts zero network calls on refusal (Task 2) |
| T-06-29 | Repudiation | An `mcp` skill invocation absent from the audit log | mitigate | Dispatch audits through the one existing `AuditLog` on the same path as every other type; asserted by test |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | No new installs; `mcp` audited and confirmed at plan 06-02's blocking human checkpoint |
