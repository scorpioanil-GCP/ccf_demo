`conftest.py` provides THE shared fixture (D-17) that the ArtifactStore, A2A, and adapter
proofs all reuse. Mechanics, verbatim from research Pattern 4:
- The **child** creates `socket.socket()`, `bind(("127.0.0.1", 0))`, `listen(64)`, reads
  the OS-assigned port from `getsockname()[1]`, then hands the bound socket to uvicorn
  via `uvicorn.Config(...)` + `server.serve(sockets=[sock])`. It prints
  `READY {port}` on stdout with `flush=True` once `server.started` flips.
- The **parent** fixture spawns the child with `subprocess.Popen([sys.executable,
  <child>], stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True)` and blocks on
  `proc.stdout.readline()`. That blocking read IS the readiness gate.
- Hardening the prototype did not need: if `readline()` returns empty (the child died at
  import), fail the fixture with the child's captured stderr rather than raising an
  opaque `int('')` error.
- `finally:` always `proc.terminate()` then `proc.wait(timeout=10)`, escalating to
  `proc.kill()` if the wait times out. Teardown is guaranteed on test failure.

Parametrize the fixture over the child entry point so 06-05, 06-09, and 06-10 add their
servers by supplying a different child module, not by copying the fixture.

There must be no `time.sleep`, no retry-until-connects loop, and no poll in the parent.
The 5 ms `while not server.started` loop inside the child observes its own server object
and is permitted; D-16 prohibits the parent-side sleep-and-hope.
