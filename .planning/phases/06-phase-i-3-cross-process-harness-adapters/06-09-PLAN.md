  <action>
Create `runtime/ccf_runtime/a2a/typed_http.py` (plus `__init__.py`) implementing
`WireProtocol` over HTTP: a client leg using `httpx` for emit, and an ASGI receive
endpoint hosted by uvicorn accepting a signed product.

The payload on the wire is the product's **canonical bytes verbatim**, with the detached
JWS members carried alongside as transport metadata. Do not re-serialize, re-encode, or
round-trip the product through any intermediate model — the signature is over exactly
those bytes, and any normalization en route breaks verification.

**The transport performs no admission check.** It hands what it received to the caller,
which hands it to the gate. Placing the check inside a `WireProtocol` implementation was
explicitly rejected by D-12 because it duplicates the rule per transport and lets a future
transport omit it. Say this in the module docstring.

Module docstring carries the four mandatory `/runtime` blocks, with the "what this cannot
do" paragraph restated for this seam: the transport holds no `GraphWriter`, no
`GraphStore`, no assembly worker, and no route to L2 (D-12). Use D-21 language — state
what the module's declared surface and the invariant test enforce.

Constructor injection, keyword-only, injected clock. The peer address, bind address,
port, and route path are all deployment values supplied by the caller — no literals
(CINV-01, No-Hardcoding). Tenancy is a per-call argument, never a constructor field
(the CDC precedent), so one transport serving a shared fabric cannot emit into the wrong
tenant by positional accident.

Enforce the size ceiling's transport-side counterpart if the framework offers one (a
request body limit), but do not treat it as a substitute: the authoritative ceiling is the
gate's, applied before canonicalization (06-08).

This module imports nothing from `a2a` — that is 06-10's leg — and nothing from any
harness package. It sits outside `ccf_runtime.adapters.*`, so the CINV-02 lint denies
harness imports here and the 06-01 negative boundary test pins exactly that.
