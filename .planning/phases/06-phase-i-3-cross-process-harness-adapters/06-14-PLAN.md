  <action>
Create `runtime/ccf_runtime/adapters/adk/__init__.py` and `adapter.py` implementing
`HarnessAdapterProtocol` against `google-adk==2.5.0`.

Bind the four seams to the verified APIs:
1. Context injection — `LlmAgent.instruction` or `.static_instruction`. Prefer the callable
   form `Callable[[ReadonlyContext], str | Awaitable[str]]` so injection is a closure over
   the pinned Context Product and the already-rendered instructions. The closure must not
   re-resolve a prompt artifact.
2. Skill exposure — `LlmAgent.tools=[FunctionTool(func) ...]`, one per bound skill, closing
   over `Agent.invoke_skill`, with the schema derived from the function signature rather
   than hand-written. Exactly the currently-bound set.
3. Effect capture — `before_tool_callback` returning a dict to short-circuit, which is
   precisely a governed refusal; `after_tool_callback` / `after_model_callback` for the
   captured path; `on_tool_error_callback` for failures. Emission routes through
   `Agent.emit_effect` and returns a typed value.
4. Replay hooks — `before_model_callback(LlmRequest)` for the model name and the
   `Runner.run_async` Event stream for the execution trace, captured into `HarnessTrace`.

Module docstring: the four `/runtime` blocks, citation per CLAUDE.md §7.3 and D-IMPL-24,
and a "what this adapter cannot do" paragraph restated for this seam in D-21 language. No
`__ccf_mode__` tag — adapters are the semantic boundary. No prompt or instruction literals;
tool names, descriptions, and instruction content come from the agent's artifacts and
catalog entries.

Constructor takes `Agent` and its own configuration, keyword-only, and nothing else from
the fabric.

`google-adk` is the heaviest of the three, pulling FastAPI, OpenTelemetry, graphviz,
watchdog, and `google-genai`. Confirm nothing in this adapter or in
`runtime/ccf_runtime/adapters/__init__.py` causes `google.adk` to be imported when only the
`langgraph` or `claude-agent` extra is installed — the package `__init__` must not import
the adapter eagerly. Pitfall 6 makes install-time neutrality a testable claim, and 06-02's
`test_extra_isolation.py` asserts the declarative half; this task must not undermine it
with an eager import.

By this point the Protocol has been hardened against two shapes. If ADK forces a further
change, make it, re-verify the other two adapters, and record it in the SUMMARY.
