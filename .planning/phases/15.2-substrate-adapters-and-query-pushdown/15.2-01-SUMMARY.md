# Phase 15.2 Plan 01: Graph Query Semantics Prose + SUBQ Requirement Minting Summary

Normative GraphQuery semantics prose (35 `GQ-NN` clauses, semver lane v1.0.0)
implementing the D-IMPL-87 multi-segment resolution — uniform rule, induced
subgraph, CP-valued size cap, hash+ArtifactStore replay pin — plus SUBQ-01..11
minted into REQUIREMENTS.md with multi-segment-accurate texts.

## What was built

### Task 1 — docs/GRAPH_QUERY_SEMANTICS.md v1 (`3983f1a`)

The D-05 artifact-1 prose, written first per the locked ordering (prose →
fallback → adapters). Eight sections, 35 distinct backticked `GQ-NN` clause
anchors (plan floor: 24), each on its clause heading line so
`tools/lints/citations.py` cite02 anchored citations bind to it:

- **§1 Vocabulary (GQ-01..06):** GraphQuery as a value (tenant_id + as_of
  mandatory, as_of arrives as data — no clock reads below the caller); the
  three predicate families mirroring the pushable parameter contracts
  field-for-field; explicit seeds (one meaning: walk starting points);
  `allowed_entities` three-valued semantics (None = no constraint on first
  segments and fully-pushable plans; empty set = empty view, distinct from
  None; engine-authored, never in a QueryFragment); absent family = no
  constraint; the degenerate everything-question; QueryFragment union rule
  (at most one fragment per family, same-family collision refused not merged).
- **§2 Evaluation (GQ-07..12):** the as-of cut citing INV-CH7-14; policy
  admissibility exactly as `PolicyFilter._admits` (class with no declared
  classification attribute inadmissible); validity-window exactly as
  `TemporalAsOf._survives` cut 3; traversal as undirected typed bounded BFS
  (seeds included, depth_limit=0 = starts only, depth_limit=N ≤ N hops);
  walk-start selection (union of class-selected and explicit seeds); the
  fallback input contract (records retain temporal metadata; fallback MUST
  re-apply the full survival predicate — idempotent no-op over SQL as-of
  paths, IS the enforcement over verbatim payload records; INV-CH7-14
  independently enforceable at the fallback tier).
- **§3 Hop admissibility (GQ-13):** every node and edge on a path satisfies
  the segment's predicates AND set membership when present (INV-CH7-40); a
  path through an excluded node does not exist; result-set filtering named
  as the information-disclosure defect the differential corpus targets.
- **§4 Segmentation (GQ-14..20 + two worked examples):** implements the
  D-IMPL-87 resolution entry by name — the split (function of plan + data +
  CP config, never substrate), the uniform rule (survivors as
  allowed_entities; every family computes within the set; seeds keep one
  meaning), the induced subgraph (both endpoints in-set), segment-boundary
  mechanics (survivor entity URIs → allowed_entities; seed classes select
  within, explicit seeds intersect), the size cap (normative mechanism, CP
  value, default None, above-cap in-process, visible in the pinned
  sequence), the segment-answer fixed point (proven per family under the
  uniform rule — fresh statement; the void set's prefix-rule idempotence
  clause is not reproduced, and `grep -i 'maximal pushable prefix'` returns
  0), and the replay pin (per-round-trip content_hash in execution order,
  full canonical bytes in the ArtifactStore keyed by hash). Two worked
  examples against `CATEGORY_ORDER` = (policy, similarity, temporal,
  traversal): the no-Similarity one-segment plan (allowed_entities None,
  one pin) and the Similarity-bearing two-segment plan (segment 1 = Policy;
  in-process Similarity; segment 2 = Temporal+Traversal with survivors as
  allowed_entities; two pins).
- **§5 (GQ-21):** as_of(tenant, at) ≡ query(degenerate) — identical records,
  ordering, bytes (D-07).
- **§6 Answer form (GQ-22..24):** interface-owned ordering (entities by
  entity_uri, relationships by relationship_key); empty answers legitimate,
  never an error; canonical RFC3339 text timestamps with the
  lexicographic-order property.
- **§7 Tier-2 payload convention (GQ-25..28), labeled SDK-defined per
  CLAUDE.md §11:** the `graph_state` payload shape validating via
  model_validate with typed mount refusal; ProductSource = fallback
  semantics over the product's records; tenant mismatch answers the empty
  view (never a mix, never raises) contrasted with SnapshotReader's
  SnapshotScopeViolation ("a source answers questions; a pin enforces
  one"); two-direction tenant-boundary conformance tests obligated.
- **§8 Conformance (GQ-29..35):** adapters always answer (D-04, no
  capability negotiation); allowed_entities translates natively
  (wire realization adapter-internal); differential byte-identity with a
  corpus that MUST include allowed_entities-bearing and Similarity-bearing
  shapes; the translation-hook contract (whole query or None, no
  partial-family bookkeeping); safe-narrowing (MUST tenant+as-of; MAY
  policy/temporal/allowed_entities; MUST NOT traverse family); staged
  adapters (Mongo `$match` + fallback traversal) fully conformant;
  amendment policy under the semver lane with failure messages citing
  clause anchors.

The first 20 lines carry the semver lane statement: version 1.0.0, no
contract version field, differential suite as the compatibility check, v1
includes allowed_entities.
