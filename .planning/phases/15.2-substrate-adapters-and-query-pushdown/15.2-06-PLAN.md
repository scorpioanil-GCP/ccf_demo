<objective>
Ship the adversarial floor: the in-memory KV backend (D-06) that proves the seam
requires no query engine at all, plus the differential conformance suite and its
corpus generator that every subsequent adapter (SQL pushdown, neo4j, mongo,
ProductSource) will be held to.

The corpus is where the D-IMPL-87 amendment gets its query-level teeth: it MUST
generate allowed_entities-bearing queries, including the resurrection shape
(in-set seed and target, out-of-set intermediate node) that the uniform rule
exists to close — every adapter is then held byte-identical to the fallback on
exactly the shapes where the defect would hide.

The memory backend is deliberately boring: a dict store, a _GraphTxn
implementation over dicts (the seam plan 15.2-02 generalized for exactly this),
and a reader that feeds dict rows into the substrate-neutral materialization
core plan 15.2-03 extracted, then lets ccf.graph.fallback answer. It is
always-on in make ci and is the teaching example for adapter authors.

Output: memory backend with boot + manifest wiring, the differential suite, the
query corpus, schema regeneration for the manifest Literal extension.
</objective>
