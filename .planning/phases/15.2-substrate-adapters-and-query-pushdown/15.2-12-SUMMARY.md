## Assumption Verification (recorded for the gate package)

- **A1 — driver-major ↔ server-major compatibility: VERIFIED, pairing pinned.**
  `neo4j==6.2.0` (current major, exact pin) against the `neo4j:5-community`
  image (server kernel **5.26.29**) with a live Bolt round trip
  (`verify_connectivity()` + `RETURN 1` + `dbms.components()`), run before any
  code committed to the pairing. The 6.x driver speaks Bolt to the 5.x server;
  no 5.28.x downgrade needed. The pairing is recorded in the module docstring,
  the pyproject extra comment, and the ci.yml service-block comment.
- **A2 — Cypher quantifier bounds cannot be parameters: VERIFIED, exception required.**
  Both shapes were probed against the live server:
  `-[*0..$depth]-` → `CypherSyntaxError` ("Parameter maps cannot be used in
  MATCH patterns"), and the quantified `(()-[]-()){0,$depth}` →
  `CypherSyntaxError` ("Invalid input '$': expected '}' or an integer value");
  the literal control `-[*1..2]-` parses. The literal-inlining exception is
  therefore necessary and was written as specified: exactly one formatting
  site (`_reach_pattern`), validated genuine-int in [1, MAX_DEPTH_CEILING],
  Pitfall-7 docstring, unit tests pinning both the validation contract and the
  single-site claim mechanically.

## Accomplishments

- **The store envelope, faithfully.** `Neo4jGraphStore` mirrors the
  Postgres store's shape: credential-free `graph_identity` built from
  host/port/database/partition (userinfo parsed once into the driver's auth
  pair and never seen again — unit-asserted given a credentialed URI),
  `reader` property, `close()`/context management, fail-at-construction
  connectivity check, and index DDL (composite range indexes over the
  compound identities — accepted by Community 5.26).
- **The write path where write paths live.** `_Neo4jTxn` implements the nine
  typed `_GraphTxn` operations as parameterized Cypher inside
  `ccf.graph._writer` only: `MERGE … ON CREATE` reports creation through
  `nodes_created` (1 new / 0 re-arrival — the writer's idempotency signal;
  for lineage the L-axis set-union itself), reads inside the explicit driver
  transaction see its own writes, and a per-partition `CcfMeta` counter
  renders the `rowid`/`BIGSERIAL` arrival-order tiebreak. The
  supersession-chain restitch, lineage union, and content identity are all
  inherited from `BaseGraphWriter` — zero algorithm restated.
- **The translation is the 15.2-09 SQL mirror, in Cypher.** Three statements
  in one read transaction: survivors (as-of cut as canonical-text comparison,
  validity over write-time `canonical_timestamp` re-renderings — fail-closed
  NULL semantics, policy admissibility with all three GQ-08 cuts via `any()`
  over a class→prefixed-property-key map parameter and dynamic property
  access, set membership as `IN $allowed`); edges (typed crossability via the
  parameterized property form, induced subgraph under the set, endpoint
  closure against materialized survivors on every constrained answer,
  degenerate dangling-edge exemption preserved); walk (variable-length MATCH
  with the one inlined depth literal, `all()` path predicates over every node
  and edge, walk-start selection within survivors per GQ-11, reached-set
  filtering mirroring the SQL outer SELECTs). Rows feed `materialize_view` —
  no record construction, no ordering, no `EntityRecord(` anywhere in the
  module.
- **Boot and manifest wiring, complete with regeneration.** `boot()` gains
  `neo4j_uri`/`neo4j_partition` in the exclusivity check with the lazy branch
  import; `DeploymentManifest.backend` extends to
  `Literal["sqlite","postgres","memory","neo4j"]`; `load_and_boot` gains the
  environment-supplied `neo4j_uri` with preflight refusals in both
  directions; `docs/schemas/ccf.deployment-manifest.json` regenerated and the
  freshness gate green.
- **L2-write sanity beyond the suite**: a scripted run booted a neo4j fabric
  and a memory fabric through the real composition root, drove identical
  writes (upsert, supersession, idempotent re-arrival, relationship, lineage
  corroboration) through both workers, and held `as_of` answers
  byte-identical at three boundaries, history chains identical, and the
  foreign-tenant answer empty.
