Open the read seam everywhere at once: widen the GraphReader Protocol with
query() and attestation, implement ccf.graph.fallback (the reference
implementation of the prose), give BaseGraphReader a fallback-backed query()
template method — built on the substrate-neutral materialization core plan
15.2-04b extracted — with as_of() derived from it (D-07), extend SnapshotReader
so replay stays conformant, and land the property suite that audits the
fallback against INV-CH7-14/-23/-24/-26 with each ID mapped to the property
that actually asserts it (review consensus concern 9).

implementation land together, or mypy --strict and runtime_checkable conformance
break between waves. After this plan, sqlite and postgres answer any GraphQuery
conformantly (via internal scan-and-filter degrade — D-04), before any pushdown
translation exists.

The _translate_query hook is governed by the prose's translation-hook contract
clause (review consensus concern 4): strictly whole-query-or-None, with the
safe-narrowing acquisition rule — no partial-family bookkeeping exists anywhere.

Output: the seam, its reference implementation, its oracle audit, and zero churn
across the 15 as_of() call sites.
</objective>
