<objective>
Promote the two SQL backends from degrade-path answering to native pushdown:
translate GraphQuery into as-of SQL (already shipped in both dialects), policy
and validity predicates (column + JSON extraction), bounded undirected
traversal via recursive CTE with hop admissibility enforced in the recursive
term, and the D-IMPL-87 allowed_entities set translated natively — membership
predicates on entity selection, on every hop of the walk, and on both endpoints
of every returned relationship (the induced-subgraph rule). The set travels as
generated '?'/%s placeholders (an IN list; a temp-table strategy is a
documented adapter-internal alternative for very large sets — not required for
conformance because the cap mechanism governs set size upstream).

D-04 guarantees this changes nothing observable except telemetry: the
differential suite from plan 15.2-06 — including its allowed_entities
resurrection shapes — is the acceptance bar, byte for byte.

Output: translated `_translate_query` implementations in both backends, pushdown
unit tests, corpus-driven differential proof.
</objective>
