## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Endpoint closure scoped to constrained answers**
- **Found during:** Task 2 (verification — sqlite conformance leg)
- **Issue:** The Task 1 draft applied GQ-16 endpoint closure to every answer
  including the degenerate one. That pruned persisted first-class edges
  whose endpoint entities carry no claim, breaking the pinned INV-CH7-20
  conformance semantic
  (`test_relationships_are_first_class_with_their_own_lineage`) and — via
  the D-07 derivation — changing `as_of()` bytes, which GQ-21 forbids
  ("identical records... every existing call site remains valid unchanged")
- **Fix:** Closure now applies iff the answer is constrained (any predicate
  family present, or allowed_entities non-None) — closure's rationale is
  leak-by-absence of an *excluded* node, and the degenerate
  everything-question excludes nothing (GQ-05). Rationale documented in
  `_endpoint_closure`'s docstring; the GQ-16 "every answer" wording tension
  filed as **DI-15.2-01** in deferred-items.md for a GQ-35-lane amendment
- **Files modified:** src/ccf/graph/fallback.py
- **Verification:** sqlite conformance leg + tests/graph + tests/replay all
  green; as_of byte-identity pinned by test_as_of_derivation.py
- **Commit:** 5f9db56

**2. [Rule 3 - Blocking] Surface fragment change-type vocabulary**
- **Found during:** Task 3 (make ci-core)

  `tools/dump_surface.py` output
- **Fix:** Member-level entries converted to `Change type: behavior` per
