## The recommended branch order in `_declared()` — the order is load-bearing

D-08's whole argument is that a targeted refusal must fire **before** `load_binding_document`
gets a chance to describe a missing document.

1. `shlex.split` raises `ValueError` → rewritten message (a quoting error is still possible)
2. `len(tokens) == 2` → **D-07** migration message
3. `len(tokens) != 1` → generic *"exactly one token, the deployment root"*
4. resolve the token; `if resolved.is_file():` → **D-08** targeted message. Use `.is_file()`,
   **not** `not .is_dir()` — CONTEXT rejected the broader non-directory branch, and a
   non-existent path must fall through to `load_binding_document`, whose *"is not a
   deployment root — it resolves to X, which is not a directory"* message at
   `binding_document.py:548-553` is already the right report for that case
5. `document = load_binding_document(token)`
6. `if document.server is None:` → **D-06** transport-named refusal
7. `if not document.server.is_file():` → the relocated *"names no server program"* refusal,
   now naming the key and the document rather than a token
8. tenant / version checks — unchanged
9. `return _Declared(program=document.server, ...)` — the field name `program` is kept, so
   `ask()` (`:218-223`) and `_call`'s signature are untouched

## The refusal-message register, measured

Four moves, in order: **the offending literal in backticks and where it lives** → em-dash,
**what the thing actually is or the rule** → a **because-clause** naming the ruling,
invariant or measurement → often, **the remedy**. Mechanical conventions, all confirmed by
reading: **no terminal period**; backticks around every identifier; **never second person**;
**show the shape, do not merely name it**; and **`SCHEME` is interpolated, never spelled** —
`mcp_stdio.py:130-134` says why: *"Written once, so the registry entry, the refusal messages
and the tests all say the same string."* That applies to the tests too.
