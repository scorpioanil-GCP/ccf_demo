### The bundle: a frozen dataclass, three values

`ComposedDeployment(fabric, control_plane, resolver)`, modelled on
`inprocess.py:125-143`'s `_BootedDeployment` and frozen for the reason that
class gives: a live handle has no canonical serialization and never belongs in a
content hash. It deliberately does **not** carry `document` or
`schema_version` — the door already holds the document (it is what the door
passed in), and after Ruling 3 nothing door-side needs the version.

All three bundle types are public: `BootedFabric` from `ccf.deployment`,
`ControlPlaneProtocol` from `ccf.controlplane.registry`,
`ServedProductResolverProtocol` from `ccf.products.resolver` — each verified in
`__all__` by import rather than by reading the source.

### The divergence from `tests/client/fixtures/stdio_server.py` (Ruling 3)

(`stdio_server.py:123-136`). `compose.py` moves it. Recorded rather than
