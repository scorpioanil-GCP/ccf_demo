## Sampling Rate

- **After every task commit:** Run the quick command (0.42 s)
- **Any task touching the address grammar or the example:** additionally run
  `.venv/bin/python -m pytest tests/examples/test_hw1_two_transports.py -x -q`
  (5.47 s) — this is the **only end-to-end proof** and it is cheap enough to be
  a per-commit check
- **After every plan wave:** Run the full suite command
- **Before `/gsd:verify-work`:** Full suite green, plus `make ci-core` with the
  known-red gate dispositioned (see *Pre-existing Red* below)
- **Max feedback latency:** 6 seconds

**The end-to-end rule (CLNT-12 / project standard).** V-07 through V-09 and V-12
must be driven **from a `CCF_BINDING` environment variable through
`ProductClient.ask`**, on the shipped `_bound_client` pattern — not by calling
`_declared()` directly. A refusal that fires in a loader and is never reached by
a client is a gate wired to nothing.

**The sabotage rule (CLNT-12, inherited).** Every new check carries a **named
sabotage control in the same plan**. Four refusal branches means four controls
plus V-11; without pairwise distinctness, one copy-pasted generic message passes
all four assertions.

## Wave 0 Requirements

- [ ] `_contained` gains a defaulted keyword-only `base_description` parameter —
      **mechanism, and it must land before any `server:` containment test can
      assert a correct message.** Verified to leave all three existing
      containment tests green unchanged.
- [ ] `server:` containment tests in `tests/client/test_binding_document.py` —
      five limbs: three refusals (V-01…V-03), one positive (V-04), one inward
      — **RULED: D-18, refuse it by name** (Dave, 2026-08-18); implemented in plan `18.1-01`
- [ ] `tests/client/fixtures/__init__.py` — a `declare_server(root, program)`
      helper, used by **three** provisioning sites. **Named explicitly, because
      the third was missed once already:**
      1. `tests/client/conformance/conftest.py`
      2. `break_over_stdio` in `tests/client/conformance/test_mcp_conformance.py`
      3. **`_root` / `_stub_program` / `_ask` in `tests/client/test_mcp_stdio_adapter.py`**
- [x] **RULED at planning: `tests/client/fixtures/deployment/binding.yaml` GAINS a
      `server:` key.** D-06's control is therefore *"delete the key from a copy"*
      (strong) rather than *"copy unmodified"* (which would test the status quo).
- [ ] Fixture provisioning must copy the server program into the **parent** of
      the copied deployment root. Every existing fixture copies `deployment/`
      into a `tmp_path` subdirectory whose parent is empty; the repo layout
      satisfies D-10 but the copies do not.

      **MEASURED CORRECTION (2026-08-18) — `18.1-PATTERNS.md` §5(b) is WRONG on this
      point and two plans inherited the error.** §5(b) claims the copied root's parent
      *"is exactly where `_stub_program` already writes … the directory layout is
      already correct; only the wiring changes."* **It is not.** In
      `tests/client/test_mcp_stdio_adapter.py` the two helpers are called with
      *different* name arguments at every site — `_stub_program(tmp_path, "exits")`
      writes `tmp_path/exits/stub_server.py` while `_root(tmp_path, "exits-root")`
      copies to `tmp_path/exits-root/deployment`, whose parent is **empty**. Same at
      `raises`/`raises-root` (`:173`/`:177`), `garbage`/`garbage-root` (`:191`/`:193`),
      `where`/`where-root` (`:230`/`:236`), and `:205`–`:206` where `STDIO_SERVER` is
      paired with `_root(tmp_path, "refuses")`.

      **Consequence if unfixed:** five tests fail inside the irreducible 11-file
      grammar flip, and — worse — `:205` is **V-12, the healthy-path non-vacuity
      leg**. With the healthy baseline broken, **V-07 cannot be distinguished from
      it**, so D-06's control would pass for the wrong reason. That is the exact
      defect CLNT-12 exists to prevent.
