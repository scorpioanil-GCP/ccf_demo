## Deviations from Plan

**1. [Rule 2 — CLAUDE.md constraint over plan text] The address encodes an `AddressedQuestion`, not the bare `WireRequest`.**
- **Found during:** Task 1, reading the tool body the plan says the address must share.
- **Issue:** The plan specifies the fifth segment as *"urlsafe-base64 canonical WireRequest JSON"* and
  `parse_product_address -> tuple[str, str, str, WireRequest]`, and requires that reading the address
  *"returns the same canonical bytes the tool returns for the same question"*. The tool's question is
  the encoded `WireRequest` **plus** whitepaper §6.3's four required axes (`subject`, `intent`,
  `freshness`, `asked_at`); a `WireRequest` carries none of them. A handler holding only a `WireRequest`
  would have to invent three strings — CINV-01 values the SDK must never hold, which the resource
  handler's own docstring names — and read a clock for `asked_at`, the literal-instead-of-argument
  defect `D-IMPL-98` removes and `C-15` keeps client-side. Both are CLAUDE.md §11 constraints
  (*Mechanism, not values*), which take precedence over plan instructions.
- **Fix:** `AddressedQuestion(CCFContract)` — `request` (the `WireRequest` as canonical text, exactly
  the tool's `request` argument, parsed with `door_question` so the echo is the door's parse, `C-01`),
  `subject`, `intent`, `freshness`, `asked_at` (aware, refused at construction). `product_address`
  takes the four axes as required keywords; `parse_product_address` returns
  `tuple[str, str, str, AddressedQuestion]`. The client that mints an address holds every one of these
  already (they are what `ccf.client.adapters.mcp_stdio` sends the tool). The must-have truth
  *"the same canonical bytes the tool returns for the same question"* is met exactly and is proven on
  both legs; the literal *"canonical WireRequest JSON"* wording is not.
- **Files modified:** `runtime/ccf_runtime/mcp/egress.py`; recorded in the fragment.
- **Commit:** `8b7be2a`.
- **For a human to confirm or reverse.** This is the one place this plan chose a shape the plan text did
  not; nothing here is written as a ruling.
