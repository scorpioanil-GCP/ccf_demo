Proven empirically in this session: a `ProductLineage` subclass with one added `int | None = None` field hashes `7e4387d3…` where the base hashes `e0dd2fb2…`. cp-04's `artifacts/expected.yaml::perspective_content_addresses` pins two whole-vessel addresses (`205ae065…`, `838afbb0…`) that `tests/examples/test_cp_04_payload.py::declared_addresses` feeds to `CFT-G16`. This needs a dated `D-IMPL` before L-02's edit (`D-IMPL-222` amend-before-execute) — options in §A.2.
2. **A Fluree Cypher read cannot be pinned to `t`.** Measured against the live `fluree/server:4.1.4` at `localhost:8090` on a fresh two-commit ledger: the `application/cypher` route answers the LATEST state under every candidate form — headers `Fluree-T`, `X-Fluree-T`, `Fluree-Max-T`, body `opts.t`, `opts.max-t`, `t`, `from` — all silently (count 2 at `t=2` with the pin asking for `t=1`), and the path form `ledger@t:1` errors `Invalid ledger ID format`. The JSON-LD route (`{"from": "ledger@t:1", …}`) and the SPARQL route (`FROM <ledger@t:1>`) DO pin (count 1). A pin past the head answers `408 err:db/ReadAfterWriteTimeout "Ledger has not reached t=3, current t=2"`. L-01 therefore cannot be "add a header beside `Fluree-Min-T`"; a pinned read has to leave the Cypher dialect (§A.1).
3. **L-23's one-sentence precedence is already true of the tree.** `ProductClassDeclaration.max_ttl_key` names the cap; the deployment registers `src/ccf/products/contract.py::MaxTTL(seconds)` under that key (`examples/cp-00-institutional-holders/artifacts/ttl.yaml` says exactly this); `src/ccf/products/gates.py::_refuse_ttl` refuses over-cap by name (`ttl-bounds`). ### Pattern 1: Additive, sentinel-defaulted contract fields (D-10, D-IMPL-38)
**What:** every new field on a frozen `extra=forbid` contract carries a *named positive sentinel* default (`NO_…`) so every existing construction site asserts exactly what it always asserted.
**When:** `TraversalSpec`, `TraversalNeighborhoodParameters`, `HalfLifeEntry`, `ProductRequestContract`, `ContextFabricSnapshot`.
**Caveat measured this session:** a sentinel default keeps *construction* stable but NOT *content hashes* — `canonical_bytes` walks all `model_fields`. That is the mechanism behind the criterion 6 / 25 conflict and behind `GraphQuery` hash movement (§B.3).

### Pattern 4: Decline → fallback (D-04, `GQ-32`)
**What:** an adapter's `_translate_query` returns `None` for any query shape it cannot answer natively; `src/ccf/graph/fallback.py` answers byte-identically. Measured precedent: Fluree declines over-ceiling depth, unencodable policy keys, oversized bodies, and capped walks.

### Anti-Patterns to Avoid
- **Keying gate coverage on function names or on `id in file`.** Measured across the ladder: three products, three conventions (cp-00 and cp-01/cp-02 cite ids in docstrings; cp-03 and cp-04 in function names). `D-IMPL-224` forbids substring matching; the checker resolves the DECLARED `test:` reference against a real `pytest --collect-only -q` (the 24.4-12 pattern).
- **Reading `DebtSignal.FAIL_CLOSED` as the debt gate.** `assess_debt` sets it; the only `src/`/`runtime/` reader is `runtime/ccf_runtime/workflow/engine.py` (measured); `debt_tolerance` occurs **0** times in `src/` + `runtime/`. L-14 compares `D_c` against a tolerance, not a signal.
- **Converting `AssemblyRefused` from exception to value.** `docs/surface-changes/24.1.1-03-a-refusal-returns-as-data.md` records that the exception is KEPT for identity disagreements. L-11 adds a value KIND beside it; it does not retype the exception.
- **A second registry key answering to one operator key.** `src/ccf/operators/registry.py::OperatorRegistry.register` raises `DuplicateOperatorKey`; a parameter variant of `TraversalNeighborhood` cannot be registered twice in one registry, which is why a sibling key is the cleaner L-06 (§B.2).

## Common Pitfalls

### Pitfall 1: A sentinel-defaulted field is hash-neutral (it is not)
**What goes wrong:** L-02 (and any `TraversalSpec`/`ProductLineage` addition) moves every content address. **Why:** `canonical.py::_normalize` walks all `model_fields`. **How to avoid:** get the criterion-25 ruling before the L-02 edit; expect the `GraphQuery` pin movement and bump the semantics version. **Warning sign:** `CFT-G16` RED with two moved addresses.

### Pitfall 2: "Pin `t` with a header"
**What goes wrong:** the Cypher route silently answers latest under every header/body form (measured). **How to avoid:** the pinned read rides JSON-LD `from: ledger@t:N` or SPARQL `FROM <ledger@t:N>`; write the probe as the criterion-5 test itself so a future server change is caught. **Warning sign:** floor and pin "agree" on a ledger that advanced.

### Pitfall 3: Registering the same operator key twice for a parameter variant
`DuplicateOperatorKey` is fatal by design; a sibling key enters the n² suite for free.

### Pitfall 4: Keying the checker on function names or substrings
Measured false readings (0/8, 0/9, 0/9). Resolve `test:` against `pytest --collect-only -q`; define "a test names an id" over function names AND function docstrings (both conventions), never module docstrings (cp-03's retired `OFS-G14` lives in one) and never `id in file`.

### Pitfall 5: The Fluree link carries no direction
`fluree_write.py` writes both `CCF_LINK`s FROM the interposed edge node; a directed variable-length pattern is not expressible — decline to the fallback (D-04) rather than approximate.

### Pitfall 6: The examples' order makes L-13 fire before their own inert branch
`produce.py` calls `refuse_request` first; four gates flip on the return trip for that reason alone (§Flip Roster) and `CFT-G06` flips or not depending on what `detail` carries. Decide `detail`'s content deliberately; re-measure.

### Pitfall 7: The No-Hardcoding lint will not catch an inert-parameter set literal
Its three rules are prompt-shape, numeric-table, factory-bypass. Criterion 15's RED must come from the contract test.

### Pitfall 8: A tool that translates a raised exception changes `isError`
`door_answer` returns a SUCCESSFUL result with a refusal inside; a test asserting `isError` for an over-ceiling depth flips. Decide whether `AssemblyRefused` is translated at the door and name the flip.

### Pitfall 9: `HalfLifeDebtProfile` does not exist
Cite `DebtProfile`. (The original pitfall also claimed `.continue-here.md` is absent; rejected at orchestration — the file is tracked. Read it; its standing rules bind.)

### Pitfall 10: A `gates.yaml` `test:` field is one string
cp-01's `CPR-G01` and cp-02's `FTS-G02` each have two executing tests; pick one per row or widen the hand-authored schema (docs-only).
