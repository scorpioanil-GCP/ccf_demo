## TWO QUESTIONS FOR DAVE — both change what gets built

### Q1 — `F-12`: the correct fix does *not* unblock cp-05, and that collides with the exit criterion.

cp-05's `request_contract` authors `unsupported_arguments` as a **list**; the SDK requires a
**mapping** of name to reason prose (`24.5-L-13`). Two readings, and they build different things:

- **(a) The SDK's shape is right; cp-05's document is malformed.** Then `F-12`'s fix is *boot-time
  refusal by name* — a better error, earlier. **cp-05 still cannot run unchanged**, because its
  document is wrong. The exit criterion's *"unchanged cp-05 declarations"* is then unreachable
  through no fault of the resolver, and the phase needs the criterion amended to say so.
- **(b) Requiring reason prose is over-strict authoring ergonomics.** Then `from_declared` accepts
  a bare list (reason prose optional), cp-05 runs unchanged, and the exit criterion stands as
  written — but the SDK has been shaped by an example, which is the thing this phase exists to
  stop.

**I recommend (a)** and amending the exit criterion, because (b) is the drift you just ruled
against. But (a) means accepting that one of cp-05's three config deltas is permanent, and that is
your call, not mine.

### Q2 — `F-11`: the naive fix is a Control Plane bypass.

cp-05 declares `permitted_classifications: []` **on purpose** and substitutes the family per
request. If the SDK simply lets a deployment replace declared operator parameters at request time,
the Control Plane's declared envelope becomes advisory — a deployment could widen its own
entitlements per question, and `CLAUDE.md` §10's Control-Plane-as-audit-plane commitment would not
hold. Two shapes:

- **(a) Governed conditioning.** The SDK binds declared parameters *against* the request through a
  seam shaped like `plan_factory` — the declaration remains the envelope and the request selects
  within it, never past it. Safe; may not express cp-05's empty-declaration idiom, in which case
  cp-05's idiom is itself the finding.
- **(b) Deployment-supplied substitution.** A callable, like `debt_scorer`, that returns the
  parameters for this request. Expresses cp-05 directly; opens the bypass unless the result is
  re-validated against the declaration.

**I recommend (a).** It is the reading in which cp-05's `permitted_classifications: []` is
evidence about *cp-05*, not a requirement on the SDK.
