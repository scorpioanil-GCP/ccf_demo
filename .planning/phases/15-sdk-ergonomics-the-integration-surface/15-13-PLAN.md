Rewrite `run.py` as the call spine an adopter would actually write.

Delete `_load`, `_instant`, `_resolution_spec`, `_envelopes`, the fourteen-line registration
prologue, the eight-line `boot` call, and the 64-line inline operator block. Replace the
first six with one `load_and_boot(manifest_path, registry=..., database_path=...)` call and
the operator block with one `build_operator_registry(parameters=..., view=..., pins=...,
policy_bundle_key=...)` call. The corpus boundary stays an explicit line in adopter code —
the view is constructed by the example at the boundary it names, then handed to the builder.

Keep in adopter code, deliberately and with a comment saying why:

- The projection Π (`QuickstartPlan`) — whitepaper §7.5, genuinely deployment code and never
  a rewrite target.
- The `ProductLineage` the product declares, and the `run_gates` call taking
  `engine_resolved=execution.operators_invoked` as a **separate** argument. These are two
  independent sources and the gate exists to catch a producer misdeclaring; a helper
  computing both from one input would make lineage strict equality tautological.
- The `build_replay_record(...)` call, with `policy_bindings` built from the pins the adopter
  reads off `BootedFabric.pins`. D-06 requires that line to stay here.

Change `QuickstartPlan.required_operators()` to return the operator keys declared in the
artifact rather than `operators.keys()`. The plan's declaration and the engine's resolution
must remain two mechanisms; reading the registry's own keys is the shortcut that, copied
eight times, would harden into the SDK's demonstrated pattern.

Remove every `assert` and every `print` — they move to `tests/` in Task 3.

Rewrite the module docstring. Two of its current sentences become false under D-09 and must
not survive: "thin loading and **asserting** logic" and "Exit code 0 means every assertion
below held." Replace them with an accurate statement — the file demonstrates the call spine,
its assertions live in `tests/examples/test_quickstart_output.py`, and `make example-00`
running clean means the spine executed. Keep the No-Hardcoding claim, which stays true and
gets stronger: deleting the artifacts leaves nothing meaningful to run.

Re-point the snippet markers. `[start:ontology]` and `[start:ingest]` currently bracket
exactly the code this deletes. For each of the 16 markers in this file, either re-point it at
the replacement call or delete it together with its `public/` include. `make docs-strict`
catches an orphan; it does not catch a marker that still resolves but now brackets the wrong
thing, so check each one by reading the including page.
