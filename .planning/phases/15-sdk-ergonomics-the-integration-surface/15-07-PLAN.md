<objective>
Make the resolution spec a first-class, closed-world artifact class reachable through
`parse_artifact`, and absorb the content-hash churn that follows as one reviewed event.

Purpose: this is the phase's highest-duplication target — a 20-line hand-marshaller
repeated across nine files whose target types **already match the YAML keys exactly**
(`assembly/worker.py:71-114` against `00-quickstart/artifacts/ontology.yaml:29-70`). Three
things stand in the way and this plan removes all three: no `semver` field (D-IMPL-77:
add it in place, no wrapper — a wrapper would change `boot()`'s signature, the one contract
D-05 preserves), the two operator-facing attribute maps riding in the same document (D-03:
split by consumer), and no registered `ArtifactClass`.

Adding `semver` changes `content_hash(spec)`, therefore every `resolution_spec_version` pin,
therefore every replay record carrying one. That is the phase's largest blast radius, which
is why D-IMPL-77 gives this its own plan with its own regeneration checkpoint — so the churn
is never confused with a rewrite defect.

Output: the semver-carrying contract, the `ccf.resolution-spec` class, round-trip and
closed-world tests, a reviewed expected-output regeneration, and two surface-change entries.
</objective>

Four parametrized tests:

1. **Round-trip identity.** `parse_artifact(document, K)` → serialize the resulting contract
   → re-parse → the two objects compare equal.
2. **Content-hash stability.** `content_hash` of two independently parsed instances of the
   same document is identical. This is what makes a registered pin reproducible.
3. **Closed-world refusal.** Adding an unknown key to the document raises
   `ArtifactLoadError`. For `ccf.resolution-spec` use the three keys D-03 moves out —
   `tenant_id`, `classification_attribute_by_class`, `similarity_corpus_attribute_by_class` —
   so the test states the split's purpose rather than a synthetic key.
4. **Missing semver refusal.** A document with no `semver` raises `ArtifactLoadError`.

Add a vacuity test asserting the parametrization list is non-empty and grows: assert it
covers at least every class currently in `SDK_ARTIFACT_CLASSES`, so a class added by a later
plan without a round-trip case fails here.

Module docstring carries the enforces / does-not-enforce discipline: it enforces that a
document survives parse and re-parse with a stable hash and that unknown keys are refused;
it does not enforce that any deployment's document is semantically correct, nor that the
contract's field semantics match the fabric's use of them.
