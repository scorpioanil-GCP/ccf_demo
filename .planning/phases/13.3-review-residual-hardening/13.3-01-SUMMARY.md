# Phase 13.3 Plan 01: Experience-Builder Hardening Summary

Fail-closed `tool_allowlist` validation plus allowlist-conditional provider
requiredness and CINV-01-consistent description parameterization on
`build_experience_server`, pinned by four construction-time unit tests.

## What Was Built

**`runtime/ccf_runtime/mcp/experience.py`**

- **D-01** — before the `allowed = ...` resolution, an allowlist naming any
  tool outside `EXPERIENCE_TOOLS` raises `ValueError` listing the sorted
  unknown entries and the sorted known set. The former behavior (register
  nothing, say nothing) let a deployment's intended surface and its served
  surface diverge silently.
- **D-03 / D-04** — `context_provider`, `lineage_provider`,
  `replay_record_reader`, `get_context_description`, `get_lineage_description`,
  and `get_replay_record_description` are now `X | None = None`, names and
  keyword-only status unchanged. Requiredness moved to registration time and
  is conditional on the allowlist: each `if <TOOL> in allowed:` block
  None-checks both legs and raises `ValueError` naming the tool constant via
  the shared `_missing()` phrasing. Each block binds a narrowed local
  (`context_seam` / `lineage_seam` / `replay_seam`) before the `@server.tool`
  closure so `mypy --strict` stays clean.
- **D-12 / D-13** — new optional `list_agents_description` and
  `invoke_agent_description` params; both agent tools now register with
  `description=`, defaulting to `DEFAULT_LIST_AGENTS_DESCRIPTION` /
  `DEFAULT_INVOKE_AGENT_DESCRIPTION`. They previously fell through to their
  inner functions' docstrings — the CINV-01 unevenness the review flagged.
- **D-14** — new optional `product_resource_description` param plus
  `DEFAULT_PRODUCT_RESOURCE_DESCRIPTION`, passed to the templated
  `@server.resource(...)` decorator. The pinned FastMCP `resource()` accepts
  `description: str | None` (verified at `mcp/server/fastmcp/server.py:540`),
  so RESEARCH.md assumption A1 held.
- Docstring Args/Raises sections extended in the module's existing citation
  style, citing D-01/D-03/D-12/D-13/D-14 (Dave, 2026-08-02) and CLAUDE.md
  §6.4/§7.1. All three default constants are one sentence, well under the
  lint's 200-char prose threshold.

**`tests/crossproc/test_experience_edge.py`** — a `_builder_kwargs` helper
supplying only the unconditionally-required seams, plus four tests:
unknown-allowlist-entry, allowlisted-without-provider,
allowlisted-without-description (all `pytest.raises(ValueError)` with the
offending name asserted in the message), and default-description advertisement
via `anyio.run(server.list_tools)` compared exactly against the `DEFAULT_*`
constants.
