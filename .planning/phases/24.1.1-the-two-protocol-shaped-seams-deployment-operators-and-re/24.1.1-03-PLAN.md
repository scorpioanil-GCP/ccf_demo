<objective>
Close `D-60`: let a conforming assembler RETURN a governed refusal, in a codebase whose stated
posture is that a refusal is DATA.

Purpose: `src/ccf/agents/assembler.py::ContextAssemblerProtocol.assemble` returns
`AssemblyOutcome` and nothing else, so an assembler receiving a governed refusal can only raise
— while `src/ccf/products/request.py::refuse_request` RETURNS a `ProductRequestViolation`, and
`src/ccf/products/request.py::ProductRequestViolation`'s own docstring states the posture:
*"The refusal is a returned value, not an exception ... a refusal returned as data cannot be
swallowed by a bare `except`."* This phase converts; it does not invent.

Output: a widened Protocol return type, a reference assembler that actually demonstrates it,
and a fragment.
</objective>
