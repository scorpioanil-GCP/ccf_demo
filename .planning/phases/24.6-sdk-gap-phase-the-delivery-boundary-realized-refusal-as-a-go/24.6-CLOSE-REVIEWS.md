## For Dave — six questions the panel converged on, each measured, none disposed here

- **P-A — the door releases what a non-reference resolver hands it, recorded or not, disclosed or not.**
  Raised by all three reviewers across seven bundles (codex 3.2/3.3/4.4/6.2/8.1/12.2; cursor B2, A5, B4-3,
  B8-2, 9.1, 11 B1; gemini 3.1, 11.1/11.2). Measured: `src/ccf/products/door.py:523` returns a served answer
  with `replay_ref=None` for a bare `ServableProduct`; `:636` envelopes a bare refusal value with
  `envelope_for` — no recorder, no `disclose` — and the transports encode it; several tests assert release
  with `NO_REPLAY_REFERENCE` as the door's honest report. Criterion 36 is enforced at CONSTRUCTION (no
  recorder → no door) and inside the REFERENCE resolver (`GovernedResolver` records on all three branches);
  it is not enforced at RELEASE. So a deployment that plugs a Protocol-conforming custom resolver returning
  bare values gets a well-formed governed answer with nothing behind it, and a bare refusal's INTERNAL
  `detail` crosses undisclosed. Options: (a) the door refuses to release a governed determination that
  carries the sentinel / `None` (release-time enforcement: *failure to record is a failure to decide*), with
  the tests that assert the sentinel path rewritten — a behavior change with a surface fragment; (b) keep
  as is and document conformance as the resolver's obligation; (c) have the door record and disclose bare
  values — a transport mint, contrary to the ruled invariant. Recommendation: (a), as the next phase's
  first row, not in-phase.
- **P-B — the experience server's product RESOURCE dereferences the resolver's return.**
  `runtime/ccf_runtime/mcp/experience.py:993-1000`: `servable = product_resolver(...)` then
  `servable.product`, with no `door_refusal` / `served_answer` (the egress door runs both at `:1027-1049`).
  A resolver returning a `RefusalEnvelope` or `ServedProduct` there raises `AttributeError` → the opaque
  failure id. Criterion 25 was scoped by Amendment 2 to the three ENTITLEMENT paths, which plan 16 shipped;
  this is the resolver-refusal path on the third door, outside that scope. Fix is the egress pattern (~15
  lines) plus the resolver Protocol's declared return widened — a surface change. (codex 1.2, cursor B4)
