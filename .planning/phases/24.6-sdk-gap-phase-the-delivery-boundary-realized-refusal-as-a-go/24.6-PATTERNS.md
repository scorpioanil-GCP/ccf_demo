```python
    @field_validator("forced_llm_threshold", "fail_closed_threshold")
```

```python
    * ``requested`` absent, or not a finite number → ``declared``. ...
    * otherwise → ``min(declared, requested)``. A request may only tighten. ...
    """
    if declared is None:
        return None
    tightened = _as_finite_decimal(requested)
    if tightened is None:
        return declared
    return min(declared, tightened)
```
