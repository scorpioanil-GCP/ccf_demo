## Findings for Dave

- **F-1 (a question the fix scoped rather than decided).** Dave's sentence is *"a default naming a
  parameter the contract does not expose"*, which presupposes a contract. A class that pins **no**
  request contract but declares `default_debt_tolerance` is left servable (three fixtures in
  `tests/products/test_structural_gates.py` hold that pair; `test_a_class_pinning_no_contract_is_out_of_scope_and_stays_servable`
  pins the scoping and goes red the day it is decided silently). Options: (a) leave it — a class with no
  contract validates no question, so the failure this check prevents cannot arise; (b) widen the rule so
  a default with no contract behind it is also a malformed declaration, refused at registration/boot.
- **F-2 (the `full` reading, restated from the ruling entry).** `policy_bindings` is normalized at every
  level below `full` and left alone at `full`; if "the same disclosure level" was meant to include `full`,
  that is one more table row.
