## What Was Built

- **replay_server.py** — `_load_fixtures` now pairs each ordinal response with its `*-request.json` sibling (former skip removed). The `replay` handler reads the body (`await request.json()`), computes a per-path `fingerprint()` — Anthropic: `model`, sorted tool names, message count; Gemini: sorted `functionDeclarations` names, contents count (no model field; it rides in the URL path) — and returns HTTP 500 with `path`/`ordinal`/`expected`/`actual` on mismatch, mirroring the existing "fixtures exhausted" loud-fail shape. Malformed JSON bodies get the same loud 500 diagnostic (T-13.2-09), never an unhandled exception. Ordinal serving order retained.
- **tests/examples/test_ext00_fixture_schemas.py** — parametrized over `sorted(FIXTURES.glob(...))` (fixture counts are data, not contract): Anthropic responses via `anthropic.types.Message.model_validate`; Gemini responses via the SDK client's `_from_response` parse path; request fixtures via structural key/shape assertions (Anthropic request types are TypedDicts, RESEARCH A1); plus a fingerprint drift-detection unit test importing `replay_server` by file path.
