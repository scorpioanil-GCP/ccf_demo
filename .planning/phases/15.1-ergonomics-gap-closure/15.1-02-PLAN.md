boundary.

`load_and_boot`, so the artifact author does not have to know which of two registration paths
their class belongs to.

migrated entries across 11 manifests plus the deployment fixture set.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest document → Control Plane registration | An entry's declared mode decides which governance obligations run |
| register_versioned's return value → ArtifactPin.version | A refusal object crossing here would be recorded as a version |
