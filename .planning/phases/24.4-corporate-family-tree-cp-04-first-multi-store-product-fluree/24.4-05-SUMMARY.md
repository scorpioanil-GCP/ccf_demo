## The five things this plan was told to get right

**1. Every assertion and every control drives the SHIPPED code.** The module
imports `normalize_edges` (including its `directions=` parameter, which is how
criterion 22's flipped arrow reaches the shipped normalizer), `detect_cycles`,
`enumerate_family_triples`, `FamilyEdges.from_pairs`, `FamilyEdges`,
`family_predicate_directions`, `family_predicate_iris`, `resolve_anchor`,
`read_node_facts` and `FINDING_OWNERSHIP_CYCLE` from
`examples/cp-04-corporate-family-tree/deployment.py`. It defines no detector and
no normalizer. Three checks hold this: the scoped grep
`grep -nE 'def [A-Za-z_]*(cycle|normaliz)' … | grep -vE 'def test_'` returns
nothing; the module asserts each shipped function's `__globals__["__file__"]`
lies under the example directory, so a sibling example that won the bare name is
caught; and the module pins the complete roster of its own non-test definitions.

**2. The wrong-method numbers come from `expected.yaml`.** All three `yields`
(130, 59 and the finding count), the wrong roster, the declared census figures
and the descriptions are read from the `wrong_methods:` block. The module
contains no integer literal of any value — proven by walking its AST — so no
number in it can be authored.

**3. Criterion 45 covers criteria 14 through 18, with the grep controlled.**
The mechanical gate is
`grep -nE '(^|[^0-9A-Za-z_])(0|1|2|5|7)([^0-9A-Za-z_]|$)'` — the portable
`( |$)` form, because `ugrep 7.8.4` here rejects `\b` inside an alternation.
It returns **nothing** over the module, in code, comments and docstrings alike.
Controlled six ways: five one-line decoys carrying `== 2`, `== 0`, `== 7`,
`== 5` and `== 1` each make it fire, and a decoy carrying only
`declared()["cycle_1"]["members"]` does not — so the expression distinguishes a
figure from an artifact key rather than matching any digit it sees. The plan's
AST gate also runs clean.

**4. Criterion 18's surviving half only.** No LEI on any of the six members;
seven classes on the first circuit's three and five on the second's, asserted
per member from the artifact and as SETS. The struck trailing clause is asserted
nowhere: the module contains no claim about walk behavior, admitted sets, class
boundaries or a stopped-at node, and `CFT-G17` is named nowhere in it.

**5. Rosters, not cardinalities.** Every roster-bearing criterion asserts the
roster: both circuits' ordered members, both closing edges, the six members'
typing roster, cycle two's external in-edges as an empty list, the acyclic five,
and the control roster by set equality. The one place a bare non-emptiness
assertion appears is `roster_blind`, which exists to be shown PASSING where the
roster assertion fails — and it is written as a truth test so the module carries
no instance of the form `D-13` forbids.

## The sabotage campaign

**Round one: 31 applied, 26 RED, 1 mis-anchored, 4 GREEN.** Round one's four
green results were each examined under this phase's own rule — suspect the
control before the subject — and all four were the control's fault or aim.

The control gained two assertions it was missing. |
| `_rotate` reduced to a no-op | **a real finding, recorded as deferred item 2.** `detect_cycles` explores a neighbour only when `neighbour > start`, so every circuit reaches `_rotate` already starting at its minimum — measured by spying on the function: two circuits, both already minimal | rotating to the LARGEST member instead — RED on both roster assertions, so the rosters are genuinely order-sensitive |
| `roster_blind` weakened to `assert True` | criterion 23 expects that assertion to PASS, so a sabotage making it pass more easily cannot be caught | `assert not findings` — RED, proving the blind assertion is really invoked |
| `fails()` returning early instead of raising | the inserted return sits on the branch reached only when the gate PASSES, and in the real controls the gate always fails, so the sabotage was on unreachable code | the `except` arm returning an empty string — RED on all three controls, proving the failure message is really read |
| the arrow-flip sabotage on `source-vocabulary.yaml` | mis-anchored: the anchor text occurred zero times | re-anchored on the IRI plus the direction line — RED |

**Round two: 10 applied, 10 RED.** Total across both rounds: **41 sabotages,
36 caught on the first aim and 5 caught after re-aiming — every check in the
module has been observed RED at least once.**

**Both instruments proven in both directions, separately from any control.**
`fails()` returns the message when handed a gate that raises and RAISES when
handed one that passes; `roster_blind` returns when handed a non-empty tuple and
raises on an empty one. An instrument that cannot fail proves nothing about what
it is silent on.

**The No-Hardcoding lint, controlled properly.** `make lint` is silent on the
module. The first positive control — a plausible-looking system prompt — did
NOT make it fire, and the reason is the one this phase has already recorded:
the string scored 1 against a threshold of 2 (two sentences, second person, no
braces), so `rc 0` looked like a clean tree. A string scoring 3 (four sentences,
second person, three braces) makes the lint fire with the file and the line, and
the tree is clean again after removal. **A control that scores under the
threshold is not a control.**

## Two judgment calls, named rather than buried

**Criterion 19's predicate is a named constant.** Nothing in `expected.yaml`
distinguishes it — three predicates give the anchor exactly one child — so a
derivation would have been an invention wearing a citation. It is pinned by
three checks instead: membership in the deployment's declared roster,
membership in the acyclic five, and the anchor's walk over it reaching the
declared child count for THAT key. Sabotaging that count to zero goes RED.

**The module is marked for the graph leg only.** Every figure it asserts —
circuits, class chains, absent LEIs — is Fluree's. The attribute leg is still
seeded, because `cp_04_seed.seed` is one routine that refuses to return until
both stores read back what the fixture carries.
