    `CCF_CP_04_FLUREE_LEDGER`, `CCF_CP_04_POSTGRES_DSN`) and holds no host, port, path or
    credential in its source.

    Its module docstring states, in the voice `dump_cp03_fixture.py` uses, that regenerating
    the fixture is a deliberate act landed in the same reviewed commit as the figures it moves
    — never an automatic refresh.

    THEN write `tests/examples/cp_04_seed.py` — not a test module, a helper the six cp-04 test
    modules import. `tests/conftest.py` line 238 makes `fluree_url` `scope="session"` and
    env-driven: ONE server, no per-module container, and no analog of the fresh-schema isolation
    `postgres_dsn`'s docstring describes. Six modules — plans 04, 05, 09, 10, 11 and 12 — each
    transact this same fixture. Transacting a fixed ledger name six times duplicates every triple
    and moves every census figure; and this repository has already shipped a red `leg-postgres`
    on `main` from shared CI fixtures colliding by collection order.

    So the helper exposes, at minimum:

    `ledger_for(module_name: str) -> str` — a name nobody else can be using, on
    `tests/graph/test_fluree_backend.py`'s `_fresh_ledger` precedent (`ccf:probe-{uuid4().hex}`).
    Shape it `ccf:cp04-{module_stem}-{uuid4().hex[:12]}` so a failure message names which module
    owns the ledger.

    `schema_for(module_name: str) -> str` — the same discipline on the Postgres side, because
    `postgres_dsn` is session-scoped too and its own docstring says isolation comes from a fresh
    SCHEMA rather than a fresh server. `cp_04_family_schema.sql` must therefore be parameterized
    on the schema name rather than hard-coding one.

    `seed(fluree_url, ledger, dsn, schema) -> None` — creates the ledger, transacts
    `cp_04_family_fluree.json`, applies the two SQL files into the named schema, and returns only
    after both are readable.

    The helper's docstring names the collision it exists to prevent and cites `tests/conftest.py`
    line 238 for why the session-scoped fixtures cannot prevent it themselves.
