    for 3 would pass on a serve-time literal that happens to be 3.

    two DIFFERENT content addresses, and assert the same `max_depth` twice produces the SAME
    address, so the gate cannot be satisfied by an address that varies with anything.

    CFT-G17 — the walk is type-constrained and STOPS rather than stepping onto an entity whose
    FIBO class does not permit it. Assert the specific node the walk stops at — named in plan
    07's SUMMARY — is absent from the returned set while its parent is present. A count alone
