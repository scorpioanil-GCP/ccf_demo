### Amendment 1 — the MCP door (criterion 37 AMENDED)

Criterion 37's *"no resource is exposed"* was **false against this tree**. What ships is
a **registered resource that refuses**. `CFT-G13` now asserts three things together:
the resource **is** registered and enumerable in `resources/list`; a resolve or read
returns `ProductNotServable` and **never a tree**; the **tool is the only path that
serves**. Sabotage: **the resolver returns a payload → RED**.

The weakness is stated in the spec rather than smoothed — a registered-but-refusing
resource still appears in `resources/list`, which is strictly weaker than absence. The
submission-time weakness block is preserved **verbatim** in §F.4 Conflict 1, explicitly
labelled as the record that the weakness was stated *before* the ruling.

**`D-34` is the residual gap**, added to the spec's gap register as §F.4 **finding 9**,
same `D-04` posture and same class as `D-30` and `D-33`. **Recorded, not closed.**
`runtime/` is untouched.

### Amendment 2 — the consume path (criterion 47 resolved, criterion 34 CLARIFIED)

`ProductClient(product_id=…, adapter=…)`. **The binding stays SINGLE-STORE and is not
widened**; the two-store assembly happens **inside the product**. `CFT-G10` now asserts
**THE ASSEMBLY opened both stores, not that the RUNNER did**, and its sabotage list
gained *move the opening into a fixture loader*.

The **client-seam consistency finding** is recorded in §F.4 Conflict 2, in §G.5's
"proves" and "does NOT prove" lists, and in the closing Gate 1 section: cp-04 is the
**first `cp-*` rung to consume through the client seam at all**, it proves `D-21`'s

### Two of my own checks were defective, and sabotage is what found them

Neither would have been caught by reading the suite.

1. **C7a never matched.** It looked for `door is TOOL-ONLY \|`, and the reverted row
   reads `TOOL-ONLY**` before the pipe. It reported PASS on a row asserting the exact
   pre-amendment position it exists to catch. The suite went red only because C7b–C7e
   are independent. Fixed to `no resource is exposed|TOOL-ONLY`, with the positive
   control confirmed: the shipped row contains **zero** hyphenated `TOOL-ONLY`.
2. **C11 measured vocabulary, not content.** It matched `binding stays SINGLE-STORE`
   anywhere in the file — and **Dave's quoted ruling contains those words**, so the
   check passed on a copy whose every operative statement had been inverted. This is
   the ladder's own general form firing again: *a check that reads a token present in
   both the compliant and the violating case is measuring vocabulary.* Split into
   **C11a** (the assertion must appear in the recipe, before §F — content) and
   **C11b** (Dave's ruling is quoted verbatim — provenance).

### The instrument defect the plan carried, confirmed

The plan's own `<automated>` block cannot run on this host. `ugrep 7.8.4` rejects
`\b` inside that alternation:

```
ugrep: error: error at position 22
(?m)^## Section A( |\b)
```

It fails identically against the **known-good `CP-SPEC-003`**, which is the positive
control proving it is the instrument and not the document. The portable form
`^## Section $s( |$)` passes all seven headings on both specs and is what was used.
