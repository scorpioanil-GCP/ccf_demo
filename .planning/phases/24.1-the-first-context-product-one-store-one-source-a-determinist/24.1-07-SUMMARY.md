## Accomplishments

### Task 1 — `tests/examples/test_cp_00_is_algorithmic.py` (criterion 4)

**12 tests.** An AST walk of every `.py` under `examples/cp-*`, at any depth,
for an import of any `tools/lints/algorithmic.py::LLM_MODULES` member.

`LLM_MODULES` is **imported, never re-declared** — a vendor SDK added to the
lint arms this gate on the same commit, where a local copy would have to be
remembered. Both `tools.lints` helpers are used together: `imported_module_names`
reports only `ccf` for `from ccf import llm`, and `submodule_import_names`
supplies `ccf.llm`. That is review finding CR-02, and `algorithmic.py`'s own
docstring records the identical hole being found by execution in the SDK's own
LLM seam.

The docstring states what a green tick does **not** mean: no LLM client is
*imported*; a subprocess or an HTTP call to a model endpoint is invisible to an
import walk.

**Why this walk is new rather than a scope edit.**
`tools/lints/__main__.py::RULE_TREE_SCOPE` scopes `algorithmic` to
`("src","runtime")` deliberately — the rule keys off a `__ccf_mode__` dunder
example code does not carry. Editing a shipped gate is what `D-04` and criterion
16 forbid.

### Task 2 — `tests/examples/test_cp_readme_template.py` (`EXAM-01`, `D-21`)

The seven-heading template has had **no live subject since Phase 23** moved
`archive/examples/external/00-hello-context` out of `examples/`. Its shipped
enforcement reads its own directory's README: one file, no argument, not a glob.
This is an **additional** gate over `examples/cp-*/README.md` — the archived one

The seven names are **read, not re-typed**, by `ast.literal_eval` over

slice of `ccf` and its sibling `serve`. The extraction has its own control —
this module's predicate, run over the archived README the shipped gate already
guards, reports no problem.
