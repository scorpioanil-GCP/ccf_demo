## The instrument finding this wave produced in its own machinery

**A positive control agreed with the recorded value while the measurement
disagreed, and its agreement was evidence of nothing.** Re-implementing the
criteria detector from prose instead of running the bound instrument added a
`.strip("\n")`, moved the sha, and produced a **false STOP** on a block that had
not changed by a byte. Control B — criterion 12 deleted — reproduced Wave 1's
recorded sha *exactly*, which read as proof the extraction matched. It was not:
control B is built as `"\n".join(splitlines())`, which discards the exact
trailing newline the live sha turns on, so it returns the same value under both
normalizations. **`D-65` requires a positive control on the reader; this adds
that the control must be sensitive to the degree of freedom the measurement
turns on.** Every wave of this phase has found the class in its own work; this
is the tenth.
