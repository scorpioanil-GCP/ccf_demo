**The snippet mechanics.** `mkdocs.yml` runs `pymdownx.snippets` with `check_paths: true`,
`restrict_base_path: true`, `dedent_subsections: true`, `docs_dir: public`, and
`strict: true` IN THE FILE (not only on the CLI), with
`validation.omitted_files`/`absolute_links`/`unrecognized_links`/`anchors`/`nav.*` all set
to `warn` — **which under `strict: true` are FATAL**.

Page-side include form: `--8<-- "examples/<tree>/<module>.py:<region>"` for a named region,
`--8<-- "path/to/file"` for a whole file. In-code form is
`# --8<-- [start:project]` … `# --8<-- [end:project]`.

**The structure to copy:** `public/concepts/answers-no-document-contains.md` carries five
includes from `examples/s1-01-hello-context-product` — two whole artifacts and three named
spine regions (`spine.py:operators`, `spine.py:project`, `spine.py:serve`).

**The publication allowlist.** `tools/publish_scan.py::INCLUDE_ALLOWED_PREFIXES` is
`("examples/", "public/", "perf/baselines/", "archive/examples/")`.
`examples/cp-00-institutional-holders/...` is **already inside it — no allowlist edit is
needed**, and the tuple is guarded by
`tools/publish_scan_tests/test_publish_scan.py::test_the_publication_allowlist_has_exactly_the_expected_membership`
plus four neighbours, so an edit would be caught. Rule id on violation: `pub04-include-escape`.

**Nav registration is mandatory.** `validation.nav.omitted_files: warn` under `strict: true`
means a page under `public/` that is not in `mkdocs.yml`'s `nav:` **fails the build**.
Precedent entry: `- Answers no document contains: concepts/answers-no-document-contains.md`.

**`make docs-strict` runs four commands, in order** — criterion 8's *"all four steps"*
maps exactly onto these:

    $(ENV_DOCS) $(PYTHON) tools/publish_scan.py --pre-build
    $(ENV_DOCS) $(PYTHON) tools/publish_scan.py docs/schemas
    $(ENV_DOCS) $(PYTHON) -m mkdocs build --strict
    $(ENV_DOCS) $(PYTHON) tools/publish_scan.py site

`ENV_DOCS`, not `ENV` — the scan does `from tools.publish_scan import ...`.

**A naming trap already documented in `mkdocs.yml`:** MkDocs 1.6 treats `README.md` as an
alias for `index.md`, and where both exist it emits a WARNING, fatal under `strict`. This
does not affect `examples/` (not a docs source) but constrains anything under `public/`.

**Gates that will reach the new page:**
