The mapping came from `24.1-RESEARCH.md` §E.2, which measured it — but a mapping
nobody re-resolved is the same risk in the other direction as a fabricated
finding. **Every `path::symbol` was re-resolved at this commit through the
SHIPPED resolver**, `tools/lints/citations.py::symbol_spans`, driven over the
citation list rather than through a hand-rolled grep.

**33 of 33 symbol citations RESOLVED; 3 of 3 bare file paths exist.**

**Control:** the same resolver, given three class names that are not in the tree
in a file that is, returned **UNRESOLVED — file exists, symbol absent** for all
three — a verdict distinct from both `RESOLVED` and `NO-FILE`. The instrument
discriminates on the axis that matters.

**The control had to be written descriptively rather than as a checked
citation.** `.planning/` is inside `tools/lints/citations.py::GATED_TREES` and
`tests/invariants/test_citation_coverage.py::MAXIMUM_UNANCHORED_PY_CITATIONS` is
zero, so spelling a fabricated citation in its `path::symbol` form would turn the
gate red on the very file recording the control. Wave 4 discovered this by
accident; here it was designed around and the reason is written into the record.

**One correction the re-resolution produced.** The research names
`src/ccf/similarity/protocol.py` for the similarity index without a symbol; the
symbol is `SimilarityIndexProtocol`, and a probe for `SimilarityIndex` returns
UNRESOLVED. The mapping table cites the real one.

**The hypothesis score is stated and not rounded up: 3 confirmed / 1 partial / 1
