## THE FIRST FINDING: `D-48`'s *"registered through the open `OperatorRegistry`"* is half available

`D-48` rules step 1 an example-supplied deterministic operator declaring
category `traversal`. **It fits, exactly as the correction to my brief
predicted, and determinism was never the obstacle.**
`src/ccf/operators/base.py::Operator` says realization is unconstrained and
*"the algebra is the determinism surface"*. The one shape `apply` fixes is the
RESULT's — a view, so no scalar — and *which security is dominant* is a
**selection**: the operator returns the winning security, the edges reaching it
and the managers on those edges. `OperatorCategory` was not touched.

**What is NOT available is the seam `D-48` names.** The registry is open;
the composition path in front of it is closed.

| Reading | Result |

`build_operator_registry` dispatches on the *artifact type* against four known

**Taken, not worked around:** the operator is registered into the deployment's

lineage still names precisely the two operators the class declares, so gate 2's

use-case agnostic and additive per `D-08`/`D-10`, and NOT proposed as SDK
work** (`D-04`). Full entry in `deferred-items.md`.

## THE SECOND FINDING: the assembler seam cannot return a refusal

This codebase's stated posture is that a refusal is DATA —
`src/ccf/products/request.py::refuse_request` returns a
`ProductRequestViolation` rather than raising, *"a verdict returned as a value
cannot be swallowed by a bare `except`."*

`assemble` is typed to return `AssemblyOutcome` and nothing else. Measured:
**seven fields**, `extra=forbid`, and none can carry a refusal — the seven
construct cleanly and an eighth named `refusal` raises `ValidationError` naming
that field. So a conforming assembler that receives a violation has exactly one
way to report it: raise.

**The reference implementation does not meet this**, which is why it has not
surfaced: `DeterministicAssembler` **holds** Π's already-computed output, so
anything unanswerable was refused elsewhere before it was constructed. An
assembler that actually runs the spine is the first thing standing where the
violation arrives. `cp-00` raises `AssemblyRefused` and hands the typed
violation to its observer first, so the client renders the refusal from the
value. **Recorded, not proposed** — a remedy widens a Protocol's return type
and is not additive.

## The three tasks

### Task 1 — `deployment.py`

**~1,140 lines.** The `s1-00` section order, re-implemented for this product.

`connection` branches over the value SOURCES `backends.yaml` declares and never
over a substrate name; `source_dsn` is a **separate function reading a separate
block**, so the graph's composition and the source binding cannot be confused —
which matters more here than in `s1-00`, because here they are two substrates.
An unset variable raises with the artifact's own `remedy` string.

The read is **one SELECT**, pinned on the reported period, ordered by the
remainder of the source's primary key, and **filtered on no third axis**. The
threshold is nowhere in it.

`observed_time` is the parsed reported quarter end. **That single mapping is
what the freshness story turns on**, and the docstring says why: it becomes the
claim's `valid_from`, which is what the λ_c curve reads; scoring `observed_at`
would measure the age of *this run* and launder a source outage into a low-debt
reading. The quarter-end coarseness is written down as a property of the filing
regime, not a defect.

**Step 1 is an operator.** `DominantSecurityResolution` — key
`traversal.dominant-security`, category `traversal`, a declared parameter set
whose `content_hash` pins its behaviour, and a pure `apply`. It ranks the
candidate rendering's securities by holdings-edge count with the **tie-break
stated** (URI ascending, because a rank with an unstated tie-break can return
two answers for one input and the payload hash depends on it not doing that),
and returns the winner's subgraph. Registration is real: it goes into an
`OperatorRegistry` and is resolved back out before it is applied, so the
duplicate-key and category checks actually run over it.

`debt()` implements §E.2 with all four reasons in the docstring, and
**C's two components are read off the resolution spec artifact itself** rather
than listed in code — identity keys excluded, because a row missing one produced
no entity to count.

Π applies the threshold, uses `>=`, sorts by position descending then CIK
ascending for a **total** order, and **omits the assembled count**: a read count
beside a served count is the below-threshold count by subtraction.

### Task 2 — `assembler.py`

**~250 lines**, 0 prints, 0 marker regions. A frozen dataclass conforming to
`ContextAssemblerProtocol` structurally. `assemble` is keyword-only, reads no
clock, and returns an outcome carrying `NO_CONSULTATIONS`, empty acquisitions,
an empty skill set and the pinned `ccf-artifact://` profile reference.

Its docstring names what it is **not** and why — all three properties that make
`DeterministicAssembler` a thing to diff against rather than a thing to call —
and names why the tree stays outside `test_section_one_is_agent_free.py`
(`D-23`/`D-24`): *"Section 1 declares no agent"* is a Section-1 rule, and
bringing `cp-00` under it would fail the example on its own core design.

Two cross-checks run **after** the spine, which is stated as a property of an
in-process deployment rather than a shortcut: the tenant and the perspective in
force are facts of the *booted* fabric, and the fabric boots inside the call.

### Task 3 — `run.py`

**~230 lines**, no marker region, the only fabric-facing module in the tree that
prints. It goes **through the assembler seam** — it never calls
`produce.assemble_and_serve`.

Prints the full specification, a separator a reader cannot miss, the payload as
`json.dumps(indent=2, sort_keys=True)`, then `D_c` and its signal, the policy
version, the content address and the replay record. `--spec brief` prints the
front matter and the operator step table, sliced **by heading name** so a
document that grows a section stays printable. `--explain` adds the transcript.

**One defect not inherited.** `s1-00`'s transcript prints `ttl_anchor` under the
label *"assembly mode"*. They are two facts: `ContextProductContract` carries no
`assembly_mode` and the replay record's dimension 3 does. Both are printed, each
under its own name.
