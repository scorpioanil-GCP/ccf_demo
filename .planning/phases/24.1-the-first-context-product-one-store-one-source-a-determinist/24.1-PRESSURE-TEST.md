pressure test the SDK."* `cp-00-institutional-holders` was built against the
Context Product Specification Standard v0.3 to find out where the SDK's surface

brought in line with anything written below (`D-07`, no retrofitting).

this session. Where a number carries no control it is marked as such rather than

## 2 · What `cp-00` ACTUALLY needed — the proof, not the claim

`D-05` predicts **zero new SDK operators**. This section is the evidence.

**The operator keys the shipped deployment declares.**
`examples/cp-00-institutional-holders/ccf_config.yaml` declares
`required_operator_keys` as exactly two — `policy.principal-subgraph` and
`temporal.as-of-boundary` — and carries a parameter set for each under
`operators:`. Both keys are SDK operators: `src/ccf/operators/categories.py::PolicyFilter`
and `src/ccf/operators/categories.py::TemporalAsOf`.

**What holds them to it.** `src/ccf/products/gates.py::run_gates` compares the
declared lineage against the set the projection engine resolved, for **strict
equality in both directions**. A deployment that declared an operator it did not
run, or ran one it did not declare, is refused at gate 2 rather than served with
a false witness. The two operator steps in the recipe are therefore not merely
reachable — they are forced.

**The one operator the example supplies itself** is
`examples/cp-00-institutional-holders/deployment.py::DominantSecurityResolution`,
the §D step-1 group-and-rank ruled at `D-47`/`D-48`. It declares the existing
canonical category `traversal`, is registered into the deployment's **own**
`src/ccf/operators/registry.py::OperatorRegistry`, and adds **no name** to the
product's lineage. `src/ccf/operators/base.py::OperatorCategory` stays the closed
four and is not touched (`D-49`).

**Measured.** `.register(` appears **three** times across the example's four
modules: twice in `produce.py` registering Control Plane artifacts (a max-TTL
pin and a request contract) and **once** in `deployment.py` registering that one
example-scoped operator.

**Verdict: `cp-00` required ZERO new SDK operators**, and the SDK-side count of
operator *categories* is unchanged at four.

**What the build DID hit** is not an operator gap but a *composition-path*
gap: `src/ccf/deployment/operators.py::build_operator_registry` would not accept
the example's own operator, so `deployment.py` constructs an `OperatorRegistry`
directly. That is `GAP-E3`, recorded in §3.3 as **encountered** — the research
marked it *"record only if the build actually hits it"*, and the build hit it.

**The base-ref guard, with the control that makes an empty reading mean

member's `git diff --stat phase-24.1-base` is **empty**.

| Probe | Reading |
