<interfaces>
`src/ccf/agents/assembler.py`, the seam this example implements:

```python
@runtime_checkable
class ContextAssemblerProtocol(Protocol):
    @property
    def assembler_id(self) -> str: ...
    @property
    def assembler_version(self) -> str: ...
    def assemble(
        self, *, request: ProductRequest, perspective: Perspective, tenant_id: str
    ) -> AssemblyOutcome: ...
```

`assemble` is **keyword-only** and **reads no clock**: the instant is
`request.asked_at`, supplied by the caller at serve time and by replay at replay time
through the same code path.

```python
class AssemblyOutcome(CCFContract):      # frozen, extra=forbid
    payload: Mapping[str, Any]
    consultations: ConsultationRecord     # use ccf.agents.assembler::NO_CONSULTATIONS
    acquisitions: tuple[AcquiredContent, ...]   # () for a wholly deterministic assembly
    assembler_id: str
    assembler_version: str
    skill_set_in_force: tuple[str, ...]   # () — this assembly binds no skill
    halflife_debt_profile: str            # a pinned ccf-artifact:// reference
```

`ccf.agents.assembler::NO_CONSULTATIONS` is `ConsultationRecord(permitted=(), refused=())`
— *"a named sentinel rather than a bare pair of empty tuples"*: **this assembly reached
for nothing outside itself** is a statement an auditor can read, and it is
distinguishable from a record somebody forgot to populate only because the claim is named.

`src/ccf/halflife/debt.py::FreshnessScorer` **refuses an empty sequence by design.**
`src/ccf/halflife/debt.py::assess_debt(DebtFactors(...), profile=...)` returns a
`DebtAssessment`.

`src/ccf/projection/plan.py::ProjectionPlan` — `plan_id`, `required_operators()`,
`invoke(*, view, operator_outputs, perspective, temporal_boundary) -> ProjectionOutput`.
`ProjectionOutput` is `plan_id` + a free-form `payload`. **`invoke` is the only place in
the Mode 1 path where arbitrary deterministic computation over assembled state produces a
payload shape** — which is where the Standard's `Evaluate` capability lives in this SDK.
</interfaces>
