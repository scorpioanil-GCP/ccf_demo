### 2.1 A silent-empty-review failure this close hit, and how it was caught

**The first nine invocations returned `rc=126` in 0 seconds with 0-byte outputs.**

    /bin/bash: line 10: /home/parkave/.local/bin/codex: Argument list too long

Linux caps a **single argv string** at `MAX_ARG_STRLEN` (128 KB) regardless of the 2 MB
`getconf ARG_MAX`. All three payloads exceed it. **Had the exit code been read through a
pipe, or not read at all, this would have looked exactly like three reviewers reviewing
and finding nothing** — the same empty-review failure mode `CLAUDE.md` §3.1 warns about
for codex's sandbox, arriving through a completely different door.

Fixed by feeding every payload on **stdin** (`codex exec -`, `cursor agent -p --mode ask`,
`gemini`), each verified with a `STDIN_OK` smoke test first. Recorded here because it is a
host fact the next close will otherwise pay for again.

**Also recorded:** gemini prints a `ModelNotFoundError` stack trace for
`models/gemini-2.5-flash-lite` on an auxiliary internal `generateJson` call. Its answer
path is unaffected (`rc=0`, correct stdout, verified on a control prompt). Noted so a
future reader does not read the trace as a failed review.
