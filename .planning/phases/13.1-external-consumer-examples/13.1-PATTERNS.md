def _instant(value: object) -> datetime:
    # PyYAML resolves `...Z` timestamps to naive datetimes; attach UTC at the artifact boundary
    if isinstance(value, datetime):

    return datetime.fromisoformat(str(value).replace("Z", "+00:00"))

### `client_bare.py` (client, no LLM, no CCF imports)

**Analog (shape only):** `src/ccf/mcp/client.py` session-per-call discipline — verbatim from RESEARCH Pattern 4:
```python
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client
headers = {"Authorization": f"Bearer {os.environ['CCF_TOKEN']}"}
async with streamablehttp_client(url, headers=headers) as (read, write, _):
    async with ClientSession(read, write) as session:
        await session.initialize()
        result = await session.call_tool("get_context", {...})
        res = await session.read_resource("ccf-experience-product://...")
```
Short-lived sessions (server is `stateless_http=True`); URL/token from env only; if the client verifies bytes it hashes plain JSON itself — no `ccf.contracts.canonical` import (D-06 anti-pattern).

## Shared Patterns

### Artifact-first loading
**Source:** `producer_child.py` lines 131–141 (`_load`, `_instant`) — apply to serve.py and run.py. Every domain/deployment value (tenant, product class, tool prose, token values, model name for live mode, expected outputs) lives in `artifacts/*.yaml`; code is interpreter only (No-Hardcoding, §6.4; `make lint` covers examples).

### READY handshake
**Source:** `producer_child.py` lines 588–626 (child) + `examples/04-cross-process/run.py` lines 314–334 (parent). Apply to serve.py, replay_server.py, run.py. Port 0, poll `server.started`, print `READY <port>`, parent blocks on `readline()`.

### Canonical bytes everywhere
**Source:** `experience.py` lines 330–341; `ccf.contracts.canonical.canonical_bytes`. Fabric-side only — client legs hash plain bytes without CCF imports.

### Env-var-only determinism
**Source:** RESEARCH Pattern 3 (verified). No `if CI:` branches in any client leg; live mode = unset base-URL vars + real keys, same code.
