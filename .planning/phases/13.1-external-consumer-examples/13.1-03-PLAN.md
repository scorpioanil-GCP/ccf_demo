Bare-client shape (mcp 1.28.1, session-per-call — RESEARCH Pattern 4):
- `from mcp import ClientSession`; `from mcp.client.streamable_http import streamablehttp_client`
- `streamablehttp_client(url, headers={"Authorization": f"Bearer {token}"})` yields (read, write, _)
- `await session.initialize()`, `await session.call_tool("get_context", {...})`, `await session.read_resource("ccf-experience-product://...")`
- Short-lived session per call; server is stateless_http=True.

ADK leg (google-adk 2.5.0, verified installed):
- `from google.adk.tools.mcp_tool import McpToolset, StreamableHTTPConnectionParams` (package root — old submodule paths deprecated)
- `McpToolset(connection_params=StreamableHTTPConnectionParams(url=url, headers={"Authorization": f"Bearer {token}"}))`
- Drive loop: `LlmAgent(tools=[toolset])` + `Runner` + `InMemorySessionService` (example 03 leg precedent)

Determinism env (RESEARCH Pattern 3):
- Anthropic: `ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY=ci-replay`; SDK appends `/v1/messages` to the base URL
- Gemini/ADK: `GOOGLE_GEMINI_BASE_URL` (verified google/genai/_base_url.py:50), `GOOGLE_API_KEY=ci-replay`; keep the non-Vertex API-key path (never set GOOGLE_GENAI_USE_VERTEXAI)

1. spawn serve.py, block on its "READY <port>" line

4. assert exit code 0; terminate servers in finally
