## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External MCP client → experience server | Untrusted client input (tool args, resource URIs, bearer tokens) |
| Client legs → replay server | Local-only model-API traffic in CI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13.1-02 | Spoofing | MCP surface auth | mitigate | Phase-10 `SourceBackedTokenVerifier` (constant-time compare, fail-closed) + AuthSettings — both supplied together (Pitfall 3); no anonymous mode (D-12) |
| T-13.1-03 | Repudiation | product serving | mitigate | `ReplayWriter`/`DeliveryCapability` — unrecorded delivery unreachable (D-14); request identity via `get_access_token()` (D-13) |
| T-13.1-04 | Information Disclosure | tokens.yaml in repo | mitigate | SYNTHETIC-labeled tokens only (example-05 precedent); charter README states real deployments supply TokenSourceProtocol |
| T-13.1-05 | Elevation | wrong-tenant serve | mitigate | tenancy-as-URI-segment (INV-CH7-16, shipped); resolver raises on non-matching ProductAddress |
| T-13.1-06 | Tampering | replay server in live mode | mitigate | binds 127.0.0.1 port 0 only; live mode = base-URL env vars unset, server unused |
| T-13.1-07 | Tampering | tool input validation | mitigate | typed tool args on FastMCP tools; Pydantic extra=forbid contracts at the product boundary (project invariant) |
</threat_model>
