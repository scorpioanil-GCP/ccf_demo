# Phase 13.1 Plan 02: Fabric Side of external/00-hello-context Summary

Authenticated black-box MCP front door for a fresh one-borrower finserv fabric,
with replay records landing before bytes by construction, plus the D-09
model-API fixture replay server.

## What was built

**Task 1 — artifacts (commit ec25d45).** Fresh `first-meridian-bank` scenario
(D-07, nothing ported): one borrower (`FMB-BRW-0007`, Acme Industrial), one
revolving credit facility, four financial signals engineered so each operator
category does visible work (lineage set-union on the borrower, similarity
ranks out a stale rating narrative, policy substitutes out a restricted
watchlist note). One product (`first-meridian-bank.credit-context` v1.0.0),
one decision (extend vs hold the credit line). `experience.yaml` carries all
tool prose, auth issuer/resource values, the empty-agent-exposure declaration,
and live-mode model names; `tokens.yaml` carries SYNTHETIC active + revoked
entries (D-12). All headers carry [ADAPT]/[MECHANISM] markers.

**Task 2 — serve.py (commit 5c8ae43, 651 lines).** Boots the fabric from
artifacts (producer_child sequence: registry → boot → ingest → four-category
operators → Plan → ProjectionEngine.execute → register_product_class →
contract → run_gates → expected-block self-check, which passed on first boot
with entity_count 4). Hosts `build_experience_server` with
`SourceBackedTokenVerifier(ArtifactTokenSource)` AND `AuthSettings` together
(Pitfall 3), artifacts-declared empty agent exposure (Pitfall 2). Extends the
returned FastMCP deployment-side: `get_context(tenant, entity)`, read-only
`get_lineage` and `get_replay_record` (D-15), and one concrete non-templated
product resource via `experience_product_uri()` (Pitfall 4, D-11). Every
product-serving path goes through `_serve_recorded()`: `get_access_token()`
identity capture (D-13) → `ccf.replay.serve.serve()` (record before bytes,
D-14) → `ServeRequestRecord` artifact naming the replay URI → canonical
bytes only. Prints `READY <port>` on loopback port 0.

**Task 3 — replay_server.py (commit 63e9c9c, 141 lines).** Starlette/uvicorn
app, zero CCF imports, path-suffix routing (`/v1/messages` → anthropic
fixtures, `:generateContent` → gemini fixtures), ordinal-per-path matching,
HTTP 500 naming the exhausted path, loopback port 0, READY with empty/absent
`fixtures/`.
