## What was built

- **run.py (538 lines).** Spawns serve.py and replay_server.py with a
  blocking `readline()` on each `READY <port>` (no sleeps), builds the
  plan-03 env contract (tenant/entity derived from ontology.yaml and
  product.yaml — the plan-03 SUMMARY's harness note honored), runs the
  three legs as subprocesses, and prints six named PASS lines:
  1. all three legs exit 0 offline;
  2. the REVOKED token from tokens.yaml gets HTTP 401 (direct httpx POST
     to the MCP endpoint — T-13.1-11 stays live in CI);
  3. static `^(import|from) (ccf|ccf_runtime)` grep over client_*.py is
     empty (D-06);
  4. README has exactly seven `## ` headings (D-17);
  5. the bare leg's captured stdout shows `operators_invoked` (lineage)
     and `content_generation_path` (five-dimension record) retrieved over
     MCP (D-15), with a direct-MCP fallback when the bare leg is
     deselected;
  6. D-16: run.py captures the exact served bytes via its own
     authenticated `get_context` call, terminates the servers, resolves
     the ServeRequestRecord -> replay_uri -> record address from
     `.store/`, rebuilds the fabric from the artifacts (fresh registry +
     boot + ingest), and `ccf.replay.engine.replay` reproduces the
     product with `canonical_bytes(outcome.product)` equal to the served
     bytes. `HelloReplayEnvironment` mirrors the example-06 pattern over
     serve.py's own helpers, so record and replay share one artifact
     interpretation.
  Children are terminated in `finally` with `wait(timeout)`/`kill`
  fallback (T-13.1-14). `--legs`/`--live` argparse backs the live
  targets.
- **README.md.** Exactly the seven template headings in order; fenced
  `.mcp.json` snippet with `"type": "http"` and an env-referenced
  Authorization header (never an inline token — T-13.1-13); auth posture
  (SYNTHETIC tokens, TokenSourceProtocol for real deployments);
  experience-vs-egress rationale with the T-06-16 URI-scheme
  distinction; empty-agent-exposure note; D-10 reviewed-regeneration
  paragraph plus fixtures/README reference; live-mode instructions.
- **Makefile.** `example-ext-00` in .PHONY and the `examples` aggregate
  (so `make ci` covers it); `example-ext-00-live-anthropic` and
  `example-ext-00-live-adk` opt-in live targets, never in the aggregate.
