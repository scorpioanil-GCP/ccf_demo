# 24.1.1-04 — a governed refusal has an identity in the record

Plan `24.1.1-04` discharges criterion 9 on **Reading B**, which `D-IMPL-214` ruled and which
enumerated `src/ccf/replay/record.py` **before any edit** — the mechanism criterion 9's
amendment exists for. A refusal returned as data (`D-60`, plan `24.1.1-03`) now has an
identity in the Decision Replay record, as a named sub-structure on an existing dimension.

## What did NOT change

- **`DecisionReplayRecord` still has exactly FIVE top-level dimensions and gained no sixth**
  (`INV-CH7-80`). Evidence:
  `tests/replay/test_dimension_extensions.py::test_the_record_still_has_exactly_five_dimensions`
  gained the third-extension leg and was **watched RED** against a version of the field
  promoted to a top-level record field.
- **Every existing `build_replay_record` call site is byte-for-byte unchanged.**
  Re-enumerated by AST rather than quoted: **40 calls across 30 files**, against a positive
  control on the same instrument (`serve()` at 42). The module's own docstring said *32
  across 28*, true when plan 15.5-13 wrote it and stale since; it is corrected in the same
  file rather than left to rot.
- **`src/ccf/replay/serve.py` and `src/ccf/products/resolver.py` are untouched.** `D-IMPL-214`
  refused Reading A by name — *"A pulls serve.py and resolver.py into a short phase."* The
  consequence is unchanged and deliberate: a refusal still terminates without its own replay
  record and without a delivery. This plan gives a refusal an identity **within a record that
  was written**; it does not stand up a refusal serve path.
- **`src/ccf/products/refusal.py` is untouched — 0 diff lines — and nothing entered
  `REFUSAL_KINDS`.** `FalseAssemblyRefusalClaimError` ends in `Error`, so the AST walk does
  not claim it. **Verified with a decoy, not by reading:** renaming it to end in `Refusal`
  turned `tests/products/test_refusal_envelope.py` RED on two assertions; renaming back turned
  it GREEN.

## Surface

- Surface: ccf.replay.record.NO_ASSEMBLY_REFUSAL
- Public surface: true
- Change type: added
- Before: absent
- After: `"no-assembly-refusal"` — dimension 5's positive claim that this decision met no
  governed refusal at the assembler seam
- Why: the `NO_HITL_ACTIONS` discipline. A decision that met no refusal and a decision whose
  caller dropped the block would otherwise be the same artifact, which is the repudiation
  failure mode every sentinel in that module exists to close
- Migration: none — it is the default of a new field

- Surface: ccf.replay.record.mint_assembly_refusal
- Public surface: true
- Change type: added
- Before: absent
- After: `(outcome: 'AssemblyOutcome | ProductRequestViolation', *, claimed: 'str | None' =
  None) -> str` — derives the block from what the assembler returned, or raises when
  `claimed` contradicts it
- Why: the block must be DERIVED from the assembler's return value rather than hand-claimed,
  which is what makes *"a refusal cannot be silently absent"* a property of the mechanism and
  not of caller discipline. Public because an adopter's own assembler must be able to call it
- Migration: none — additive

- Surface: ccf.replay.record.FalseAssemblyRefusalClaimError
- Public surface: true
- Change type: added
- Before: absent
- After: a `ValueError` raised when a caller hands the minter a governed refusal while
  asserting `NO_ASSEMBLY_REFUSAL`, or asserts a refusal over an outcome that is not one
- Why: `src/ccf/agents/errors.py::FalseGrantClaimError`'s exact reasoning — the caller already
  knows the claim cannot be true, so recording it would corrupt dimension 5 at write time. It
  lives in `record.py` rather than `errors.py` because `errors.py` is outside the ruled file
  roster (`D-IMPL-214`), and the roster is judged by set equality rather than by convenience
- Migration: none — additive

- Surface: ccf.replay.record.ContentGenerationPath
- Public surface: true
- Change type: behavior
- Before: dimension 5's field map without an assembler-seam member
- After: the same map plus `assembly_refusal: str = NO_ASSEMBLY_REFUSAL`. **Dimension 5 rather
  than dimension 2** because dimension 5 is *how the delivered content came to be* and a
  refusal is that path's terminus; a refusal is not a policy binding, which is what dimension
  2 records
- Why: `D-IMPL-214` Reading B — a named sub-structure inside an existing dimension, on the
  `hitl_actions` / `workflow_step_sequence` precedent this module already carries four times
- Migration: none — sentinel-defaulted

- Surface: ccf.replay.record.build_replay_record
- Public surface: true
- Change type: behavior
- Before: the same signature without an assembler-seam keyword
- After: one added keyword, `assembly_refusal: 'str | None' = None`, threaded with the
  `if X is not None else SENTINEL` expression the three precedents use, and admitted only
  when it is the sentinel or a value that round-trips as a
  `src/ccf/products/request.py::ProductRequestViolation` — a hand-written block that merely
  looks like a refusal is the flattening `src/ccf/products/refusal.py::envelope_for` exists
  to forbid
- Why: the block has to reach the record from the caller that minted it, and the builder
  records it verbatim rather than reconstructing it
- Migration: none — sentinel-defaulted; all 40 call sites unchanged

## The hole this does NOT close, named rather than implied

**A caller who never calls the minter, and passes the sentinel by hand while holding a
refusal, still produces a well-formed FALSE record.** The block-shape check stops a
*fabricated* block; it does not stop a *truthful-looking silence*. `FalseAssemblyRefusalClaimError`
reaches only callers that ask for the check.

What would close it is the refusal **value** travelling into the builder rather than a
pre-serialized block — which is Reading A's shape, and Reading A was REFUSED for this phase
because it pulls `serve.py` and `resolver.py` in. **So criterion 9 is discharged as ruled, and
it is not discharged absolutely.** That distinction is recorded here, in
`src/ccf/replay/record.py`'s own docstring, and in `24.1.1-04-SUMMARY.md`, rather than being
left for a reader to discover — a criterion is not discharged by narrowing it to what was
convenient (`D-38`), and a limit stated is worth more at the gate than a limit implied.
