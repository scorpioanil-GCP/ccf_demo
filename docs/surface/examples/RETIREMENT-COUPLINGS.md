## Reading the columns

- **Liveness** — `live` means deleting the subject breaks something; `documentary` means it leaves stale text in a docstring, a comment or prose; `survives` means the reference is a synthetic token written into a `tmp_path` tree and never resolved on disk, so it outlives its subject rather than breaking. All three carry an owner: a documentary row is lower severity, not unowned, and four of the files this sweep is required to find carry only documentary hits.
- **Witnesses** — for a count coupling, how many of the sites the scan finds lie under a retiring path; for an inline tree-witness assertion, how many retiring paths independently sustain it. A coupling with one witness is materially more urgent than one with headroom.
- **Intermediate** — for an indirect execution, the file between the always-on test and the retiring path. The row is filed against the test, because that is where the build goes red.
- **Owner** — the plan that must act. For a count coupling it is the plan retiring the *last* witness, because that is the plan after which the floor takes its final value; the note records the wave at which the floor first breaks on the tree as measured, which can be earlier.
